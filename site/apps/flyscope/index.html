02 / The question

Look inside
the node.

A connectivity graph draws each neuron as a point. Inside, every input lands somewhere on the cell’s branches. Does that internal arrangement record connections elsewhere in the network?

  1. 01

    Fix a connection. Partner B contacts receiving neuron C: five or more records one way, fewer than five back.

  2. 02

    Map the inputs. Each source input on C is measured along C’s own branches to the nearest input from B in the same brain region.

  3. 03

    Read the far edge. Sources wired to B, an edge that never touches C, land nearer B’s inputs. Input maps alone then predict A→B for unseen sources.

03 / Unseen sources

Input maps predict connections

Predicting A→B for 200 test sources disjoint from 200 training sources, from input maps on known receivers.

0.161 AP
MaleCNS · from 0.089 with counts and size only
0.114 AP
FlyWire · from 0.069

Log loss 0.184 → 0.165 and 0.142 → 0.125; 30,702 and 21,822 scored pairs. Point estimates from one source split per specimen.

Beyond the fly brains, two adult C. elegans reconstructions also gave negative within-source differences (10 and 13 receivers), and a Platynereis larval population was too sparse to decide. These are associations within single specimens: anatomical opportunity, selective wiring, or both remain compatible.

08 / The paper

Read the study.

Xizhe Zhang · Manuscript, 2026

Synaptic organization in shared receivers predicts connectivity between input neurons

Abstract

A neuronal connectivity graph records which cells are connected but discards the positions at which their inputs enter a receiving neuron. We asked whether this internal arrangement contains information about connections between the input neurons themselves. In two adult Drosophila connectomes, inputs from sources connected to a descending-neuron partner lay nearer that partner’s inputs on a shared receiver. Mean path-distance differences were 9.4 µm in MaleCNS and 8.0 µm in FlyWire. With source-input positions fixed and reference-site counts standardized, the relationship persisted across alternative partners. We then used source-labelled input maps on known receivers to predict connections between source cells excluded from model fitting. Adding spatial-distribution and distance features to input counts and receiver size increased average precision from 0.089 to 0.161 in MaleCNS and from 0.069 to 0.114 in FlyWire, with lower probability loss in both datasets. Predictions averaged information across eligible shared receivers. These findings connect the organization of inputs within neurons to connectivity among their sources and show that this spatial information is useful for inferring connections between unseen input cells.
