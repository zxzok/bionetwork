## 一句话看懂

症状网络通常只用几百人的样本估计，边和中心性的抽样误差很大。这篇教程给出三步检查：用 bootstrap 求边权的置信区间；逐步删掉被试，看中心性排序还稳不稳（CS 系数）；检验两条边或两个节点的中心性是否真的不同。在作者的示例中，常被大书特书的介数和接近中心性几乎完全不稳定。

## 研究背景与问题

网络精神病学把精神障碍看成症状之间相互作用形成的网络（见 Borsboom 2017），2010 年代中期相关研究迅速增多。典型做法是用横断面问卷数据估计偏相关网络，再计算中心性，挑出“最中心的症状”，并推测它是干预靶点。

问题在于：大多数研究的样本量只有几百人，却要估计几十到上百个参数；很少有人报告这些估计有多精确。结果是，看起来清楚的网络图和中心性排序，可能大部分是抽样噪声。作者希望提供一个标准、易用的准确性检查流程。

## 核心思想与方法

**网络估计**：连续或有序数据常用**高斯图模型**（GGM），边权是控制其余所有变量后的偏相关；用图形 LASSO 加正则化、以扩展贝叶斯信息准则（EBIC）选择惩罚强度，得到稀疏网络（EBICglasso）。

**三步准确性检查**：

1. **边权准确性**：非参数 bootstrap（有放回重抽被试）重复估计网络，得到每条边的置信区间。区间越宽，边权越不可靠。
2. **中心性稳定性**：病例删除 bootstrap，逐步删去更大比例的被试，计算子样本中心性与全样本中心性的相关。
3. **差异检验**：基于 bootstrap 检验两条边或两个节点的中心性之差的区间是否包含 0。

::: {.callout-def}
**相关稳定性系数** $CS(\text{cor}=0.7)$：最多可以随机删去多大比例的被试，使得在 95% 的重抽样中，子样本中心性与原样本中心性的相关仍不低于 0.7。作者基于模拟建议：CS 系数不应低于 0.25，最好高于 0.5。
:::

这些方法实现于 R 包 **bootnet**，它同时提供统一的网络估计接口，可以调用 EBICglasso、Ising 模型等多种估计方法。

## 主要发现

1. **模拟示例说明问题**：作者用一个所有节点中心性其实相同的模拟网络展示，单次估计的中心性图会给人“某些节点明显更重要”的错误印象。
2. **CS 阈值来自模拟**：在 24,000 个模拟数据集中，当真实中心性都相同时，CS 系数随样本量增大也保持稳定、大多低于 0.5，约 75% 低于 0.25。据此提出 0.25 与 0.5 两条经验阈值，并明确说明它们“有一定任意性”。
3. **PTSD 实例**：359 名伴随物质滥用治疗的女性（完全或亚阈值 PTSD），17 个 PTSD 症状。多数边的 bootstrap 置信区间很宽；只有“惊跳–过度警觉”“疏离–兴趣丧失”“提醒时不安–闯入性想法”三条边可靠地强于其他边。
4. **中心性稳定性差异很大**：介数与接近中心性的 CS 系数都只有 0.05，完全不能解释；强度为 0.44，达到 0.25 但未达 0.5，作者认为其排序只能谨慎解读。
5. **差异检验**：例如强度最高的节点与另一个候选节点之间的强度差，bootstrap 区间包含 0，说明“谁最中心”无法确定。

## 局限与后续工作

- **准确性 ≠ 可重复性 ≠ 因果**：bootstrap 只评估同一总体内的抽样误差，不能保证换一个样本、一种文化或一个量表时结果相同。Forbes 等（2017, *Journal of Abnormal Psychology*）质疑症状网络的可重复性，引发与网络学派的公开争论；Fried 等（2018, *Clinical Psychological Science*）在四个 PTSD 样本中比较网络，发现既有相似也有明显差异。
- **中心性不等于干预靶点**：即使强度中心性稳定，横断面偏相关网络也无法确定方向和因果，“最中心症状”可能只是测量重叠或共同原因的结果。Bringmann 等（2019, *Journal of Abnormal Psychology*）系统讨论了中心性指标在心理网络中的适用性。
- **估计方法本身的争议**：Williams 等（2019, *Multivariate Behavioral Research*）认为在样本量远大于变量数时，非正则化方法的假阳性控制可能更好；作者在文中也承认，中心性的抽样分布本身有偏，即使不做正则化，bootstrap 区间也不能当作真正的 95% 置信区间，只能作为准确性的粗略指示；如何构造中心性的无偏估计与真正的置信区间，作者列为未解决问题。
- **多重比较**：差异检验图中未做多重比较校正，结果应视为探索性。
