## 一句话看懂

连接图只记录“谁连着谁”，却丢掉了输入落在接收神经元树突上的**位置**。这篇论文发现：如果两个输入源 A、B 彼此相连，它们在共同接收神经元 C 上的输入往往靠得更近。在 MaleCNS 和 FlyWire 两个成年果蝇连接组中，这种靠近平均约为 9.4 μm 和 8.0 μm；把这类空间特征加入预测模型，对两个从未参与训练的输入神经元之间是否相连的判断明显变好，平均精度从 0.089 提高到 0.161（MaleCNS）、从 0.069 提高到 0.114（FlyWire）。

## 研究背景与问题

[连接组：结构连接与功能连接](brain-connectome.connectome-concepts.html)中把连接组抽象成图，每个神经元是一个**没有内部结构的点**。但真实神经元是空间中伸展的树状结构：同样来自 A 和 B、同样数目的突触，可以落在 C 的同一小枝上，也可以分散在相距很远的分支上，连接图对两者一视同仁。

“物理网络”（physical network）理论主张把空间伸展的节点本身也看成网络。秀丽隐杆线虫上的已有工作（Ruach 等）发现，共享邻居更多的神经元，其突触在共同目标上更靠近。尚未回答的问题有两个：在**固定输入位置**之后，这种关系是否仍然存在？它能否用来推断**之前没见过**的神经元之间的连接？

论文选择果蝇的**下行神经元**（descending neurons, DN）作为接收者。DN 连接脑与腹神经索，身份可辨认、输入汇聚丰富，适合作为“共同接收者”。

### 三细胞设计：共同接收者与输入源对

::: {.callout-def}
**三细胞构型**：输入源 A 和 B 都向接收神经元 C 发出连接。可观测的信息是 C 上按来源标记的突触后位置（source-labelled input map）；要研究的是 A→B 这条连接。A→B 的两个端点都不在 C 上，但 A、B 都是 C 的直接上游邻居，所以这是一个局部的三节点问题。

**连接阈值**：一条连接至少有 5 条已发布的接触记录（contact record）才算存在；1–4 条的情形在不同分析中或归入“其他”，或直接排除。
:::

如果 A→B 存在，A→C、B→C、A→B 三条边正好构成[网络基序：自调控与前馈环](molecular-networks.network-motifs.html)中的**前馈环**。论文问的是：只看 C 身上的输入分布，能否读出前馈环中那条“不经过 C”的边？

### 路径距离

::: {.callout-def}
**路径距离**：把突触后位置投影到 C 的重建骨架（skeleton）最近的顶点上，沿骨架计算最短路径长度 $d_C(x,y)$，单位为 μm。对固定的 B→C 连接和脑区 $r$，源输入位置 $x$ 到最近一个 B 输入的距离为

$$d_{BCr}(x)=\min_{y\in P_{BCr}} d_C(x,y),$$

其中 $P_{BCr}$ 是 B 在区域 $r$ 内落在 C 上的输入位置集合。参照输入必须与源输入属于同一个脑区标签。
:::

神经元骨架本身是一张树状图，路径距离就是[路径、距离与最短路径算法](network-metrics.paths-distance.html)中的最短路径，只是边长为物理长度。改用欧氏距离，结论方向不变。

### 第一步：比较不同输入源（源间比较）

固定一条单向 DN 连接 B→C。向 C 输入的非 DN 源分成两组：**共享源**（同时给 B 至少 5 条记录）与**其他源**（给 B 的记录少于 5 条）。对每条连接，计算两组源输入到最近 B 输入的平均路径距离之差（共享减其他）。负值表示共享源的输入更靠近 B 的输入。

### 第二步：控制混杂——固定源输入位置

不同的源落在 C 上的位置本来就可能不同。第二步因此**固定**源 A、接收者 C 以及 A→C 的全部实际输入位置，只改变伙伴 DN：

- 与 A 相连的伙伴 B（收到 A 至少 5 条记录）；
- 替代伙伴 B′（收到 A 的记录为 0）；收到 1–4 条的伙伴排除。

两类伙伴都向 C 输入，并限定在同一脑区、C 骨架的同一连通分量内。

另一个混杂是伙伴在 C 上的位点越多，“最近距离”自然越小。论文因此**标准化参照位点数**：从伙伴的 $n$ 个不同位点中无放回均匀抽 3 个，计算到最近者距离的期望。按距离排序 $d_{(1)}\le\dots\le d_{(n)}$，第 $\ell$ 近的位点成为三者中最近者的概率是 $\binom{n-\ell}{2}/\binom{n}{3}$，于是

$$\tilde d(x,B)=\sum_{\ell=1}^{n-2}\frac{\binom{n-\ell}{2}}{\binom{n}{3}}\,d_{(\ell)}.$$

这是对所有三点子集的解析平均，不是挑最近的三个点，也不引入随机抽样误差。

### 第三步：预测未见过的输入神经元之间的连接

这一步 A、B 都是非 DN 输入源，C 仍是 DN。用 200 个源细胞之间的有向对训练，用另外**不相交的** 200 个源细胞测试，测试对的两个端点都没参与拟合。目标是 A→B 是否达到 5 条记录；A→B 的接触本身不在 C 上，也不进入预测特征。

- **计数模型**（4 个特征）：A→C 记录数、B→C 记录数、C 上可见输入记录数、C 骨架长度；
- **空间模型**（20 个特征）：在上述 4 个之外加入两源各自的空间离散度，以及 A、B 输入之间的欧氏距离和骨架路径距离摘要（最小值、第 10 百分位、中位数、近距离位点对比例等）。

两者都用 L2 正则化逻辑回归。每个可用的共同接收者给出一个概率，再对该源对的所有接收者取平均。

::: {.callout-def}
**平均精度**（average precision, AP）：把候选连接按预测概率从高到低排序，沿精确率–召回率曲线做阶梯式求和。随机排序时 AP 约等于测试集中正例的比例。连接稀疏时，AP 更能反映排在前面的候选有多少是真的。
:::

1. **相连输入源的输入更靠近伙伴的输入**。MaleCNS 13,318 条连接中，共享源与其他源的平均路径距离为 60.77 μm 对 70.18 μm，差值 −9.42 μm（95% 区间 −10.52 至 −8.31）；FlyWire 5,807 条连接中为 51.37 对 59.36 μm，差值 −7.98 μm（−9.27 至 −6.70）。按接收者平均，差值为负的比例为 82.7%（1,079 个）和 80.7%（720 个），但也有方向相反的个例。
2. **一个可辨认的环路**。上行神经元 AN19B014 同时连接 DNge006 和 DNge072，而 DNge006 也连向 DNge072。在咽下神经节（GNG）中，这对 DN 的 12 个共享源（含 AN19B014）的输入到最近 DNge006 输入的平均距离为 10.7 μm，其他非 DN 输入为 19.0 μm。
3. **固定源输入位置后关系仍然存在**。MaleCNS 中与源相连的伙伴为 64.40 μm，零输入伙伴为 73.54 μm，差值 −9.14 μm（−11.21 至 −7.07），922 个接收者中 749 个方向一致；FlyWire 中为 62.79 对 72.93 μm，差值 −10.15 μm（−12.15 至 −8.14），589 个中 483 个一致。
4. **空间特征改善对新细胞连接的预测**。测试集正例比例只有 4.30%（MaleCNS）和 3.08%（FlyWire）。加入空间特征后，平均精度从 0.089 升至 0.161、从 0.069 升至 0.114；对数损失从 0.184 降至 0.165、从 0.142 降至 0.125；补充材料中 AUROC 从 0.677 升至 0.800、从 0.712 升至 0.807。
5. **覆盖范围有限**。39,800 个有向候选中，只有 30,702 个（MaleCNS）和 21,822 个（FlyWire）有可用的共同接收者图谱而被打分；其中 79.6% 和 72.7% 综合了至少两个接收者。
6. **其他物种只是探索性证据**。两个成年秀丽隐杆线虫重建中，固定源比较的差值为 −9.88 μm 和 −5.39 μm，但只有 10 个和 13 个接收者，其中一个源间比较的区间跨过 0。Platynereis 幼虫只得到 4 条合格连接，方向不一致（平均 +6.09 μm），不能视为重复验证。

## 局限与后续工作

- **这是在投稿件，尚未经过同行评审**。方法、数字和结论都可能在审稿后修改；早期版本以 “Synaptic placement reflects shared input in Drosophila descending neurons” 为题发布在 arXiv 上，内容与本文有差别，引用时请以正式发表版为准。
- **相关不等于因果**。作者在讨论中明确指出，**解剖机会**可能是共同原因：A、B、C 的树突和轴突在同一区域交汇，既容易形成 A→B 连接，也会让 A、B 的输入在 C 上靠近。固定源输入位置、标准化参照位点数缩小了比较范围，但没有匹配更细的分支水平接触机会。结果与解剖约束、选择性布线或两者兼有都相容。路径距离是几何量，不直接等于电学上的整合效果。
- **样本单位**。每个果蝇数据集只代表一只动物，区间描述的是连接组内部变异，不是个体间变异。
- **预测的边界**。训练与测试细胞不相交，但类型可以重叠，接收者已知；每个连接组只做一次划分，对比没有区间估计；无共同接收者图谱的候选对不在评估之内。空间模型的优势也还不能拆分到“离散度”或“相对距离”。
- **后续方向**（作者提出）：在新的接收者群体上检验、重复多次源划分、评估单个接收者的预测能力，并在保持分支水平接触机会的前提下比较分支内位置。论文也指出，只匹配连接与接触数目的连接组生成模型未必能重现这一关系。

## 关联知识

- [连接组：结构连接与功能连接](brain-connectome.connectome-concepts.html)介绍了微观尺度连接组。本文提醒我们：即使在突触级连接组里，把神经元压缩成“点”也会丢掉信息。
- [路径、距离与最短路径算法](network-metrics.paths-distance.html)中的最短路径：路径距离是神经元骨架这棵加权树上的最短路径。
- [网络基序：自调控与前馈环](molecular-networks.network-motifs.html)：A→C、B→C 加上 A→B 构成前馈环。本文可以理解为用节点内部的空间信息去预测前馈环中缺失的那条边，也是一种**链路预测**问题，并与共同邻居类方法有相通之处。

## 延伸思考

1. 论文用“到 3 个随机参照位点的期望最近距离”标准化。如果不做这一步，伙伴输入位点数的差异会怎样让结果产生偏差？试举一个具体情境。
2. 作者认为解剖机会可能同时导致 A→B 连接和输入靠近。请设计一个分析或实验，尽量区分“解剖约束”与“选择性布线”两种解释。
3. 空间模型把 AP 从 0.089 提高到 0.161，而随机水平约为 0.043。你如何向一位实验神经科学家解释这一提升的实际意义？它能否直接用来指导电生理验证？
4. 在人脑 MRI 连接组中，节点是脑区而不是神经元。“节点内部的空间组织携带网络信息”这一思想，在宏观尺度上可能有什么对应物？
