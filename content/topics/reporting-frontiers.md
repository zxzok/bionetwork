## 概述 {#overview}

一项网络分析最终要以图表和文字的形式被他人阅读、检验和使用。本专题的前半部分讨论结果呈现：怎样让每张图回答一个问题并带上对照与不确定性，网络图本身怎样画才不误导，一篇网络分析报告应包含哪些部分、方法部分怎样写才能被复现，口头报告怎样组织，以及怎样审阅他人的网络分析研究。

后半部分把各专题串联起来：先概括贯穿网络科学的五条主线——度与枢纽、模块、网络上的过程、网络是构建出来的、与什么比较；再分页介绍超越“静态、单层、两两相互作用”这一经典网络表示的几个前沿方向：

- **高阶相互作用**：用超图和单纯复形描述三个及以上元素的群体作用，并以拓扑数据分析（持续同调）刻画加权网络的“形状”；
- **时间网络**：边只在特定时刻存在时，传播必须沿时间一致的路径进行；
- **多层与相互依赖网络**：多种关系、多种组学或多个模态放在同一个数学对象里；
- **网络表示学习与图神经网络**：把节点、边或整张图映射为向量，用于预测药物–靶点关系、蛋白质功能和脑网络分类；
- **可解释性与因果**：预测性能好的模型是否告诉我们机制，统计依赖的网络能否回答干预问题。

每个方向都给出定义、可手算的小例子、代表性文献与开放问题，[研究前沿与开放问题](reporting-frontiers.frontiers.html)一页把它们汇总成表。几个方向的共同教训是：表示方法越复杂，“节点和边怎样定义、与什么比较、结论对分析选择是否稳健”这些老问题就越重要。

本专题与[网络分析流程与 NetworkX 实践](analysis-workflow.html)、[研究问题、可复现分析与敏感性分析](reproducible-research.html)共同构成“计算方法与研究规范”领域：前两者讨论怎样做出可信的分析，本专题讨论怎样把它可信地呈现出来，以及方法还可以向哪里发展。

## 研究结果的图表呈现 {#figures}

### 基本原则

- **一图一结论**：每张图回答一个问题，标题写结论，而不是写“度分布图”。例如“AD 基因的最大连通分支显著大于度匹配随机期望”。
- **总有对照**：网络指标单独给出意义不大，要和零模型、另一组、另一个阈值放在一起。
- **网络示意图要节制**：上千个节点的“毛线团”图不传达信息。只画模块、枢纽或子网络，并配合定量图（分布、曲线、箱线图）。网络图本身的画法见[网络可视化：原则与常见错误](reporting-frontiers.network-visualization.html)。
- **展示不确定性**：给出误差线、置信区间、随机基线分布或敏感性曲线（见[敏感性分析与替代解释](reproducible-research.sensitivity-analysis.html)）。
- **颜色与可读性**：坐标轴标签和单位完整；配色在黑白打印和色觉障碍读者看来仍可区分。

### 选择图式：先问“要比较什么”

| 要传达的结论 | 推荐图式 | 常见替代与问题 |
|---|---|---|
| 观测值是否偏离零模型 | 零分布直方图或小提琴图 + 观测值竖线，标注 $z$ 或经验 $p$ | 只报 $p$ 值：读者看不到效应量和零分布的宽度 |
| 两组（患者/对照）的节点或全局指标差异 | 带原始数据点的箱线图、小提琴图或配对连线图 | 只画均值柱状图：掩盖分布形状与离群值（Weissgerber 等，2015） |
| 指标随参数（阈值、密度、分辨率 $\gamma$）的变化 | 横轴为参数的曲线，多组叠加，带置信带 | 只报一个阈值下的结果：读者无法判断稳健性 |
| 度或强度分布 | 对数坐标下的互补累积分布（CCDF） | 线性分箱的直方图：尾部噪声大，易误判幂律 |
| 节点排名（中心性、候选基因、候选药物） | 横向条形图或点图，带抽样不确定性（自助法区间） | 只列前 10 名：看不出排名是否稳定 |
| 模块与组成 | 排序后的邻接矩阵、模块 × 注释的热图 | 毛线团网络图 |
| 多个集合的交集（如多个数据库的疾病基因） | UpSet 图（Lex 等，2014） | 超过 3 个集合的维恩图难以读 |

::: {.callout-def}
**“与什么比较”写进图里**：一张好的网络结果图至少同时包含三样东西——观测值、参照（零模型分布、对照组或另一种分析选择）和不确定性（区间、分布或重复）。缺一样，读者就要回到正文去猜。
:::

本专题的[代码示例](reporting-frontiers.html#code)给出了两种常用图式：把两种策略（随机失效与蓄意攻击）的曲线画在同一坐标系中对照；把零模型分布画成直方图、真实值画成竖线，并在标题中写出 $z$ 分数。

### 颜色

- **类别变量**（如社团、细胞类型）用定性调色板，类别不超过约 8 个；超过时合并小类或改用标记形状、分面。
- **有序或连续变量**（如中心性、表达量）用感知均匀的单色或多色渐变（如 viridis）；**有自然中点**的变量（如相关系数、对数倍数变化）用发散型调色板并让中点对应 0。
- **避免彩虹色图**：彩虹色在亮度上不单调，会制造并不存在的边界，色觉障碍读者也难以区分（Crameri 等，2020）。
- **不要只靠红绿对比**：红绿色觉异常在男性中较常见，图中关键对比应同时用亮度、形状或线型编码（Wong，2011）。

::: {.callout-warn}
**同一变量在全文中用同一套颜色**：例如“疾病基因 = 红色、随机基线 = 灰色”一旦确定，所有图都保持一致。图例、坐标轴单位和样本量（$n$）应能让一张图脱离正文单独被读懂。
:::

## 网络可视化：原则与常见错误 {#network-visualization}

网络图（节点–链接图）是网络研究中最醒目也最容易误导的图。它的价值在于展示**局部结构**——一条通路、一个模块、一个候选基因的邻居、一组枢纽之间的连接——而不是证明全局性质。全局性质（度分布、模块度、小世界性）应该用统计图呈现。

### 三类表示及其适用范围

| 表示 | 适合 | 局限 |
|---|---|---|
| **节点–链接图**（力导向布局） | 稀疏、中小规模（约数十到数百节点）的网络；展示路径、邻居、局部模块 | 稠密时成为“毛线团”；位置依赖布局算法和随机初值 |
| **邻接矩阵图**（按社团或聚类排序） | 稠密网络、加权网络、模块结构、组间差异矩阵 | 路径难以追踪；排序方法会影响观感（Behrisch 等，2016） |
| **基于规则的布局**（hive plot、环形图、分层布局） | 按节点属性（类型、度、染色体位置、脑叶）比较多个网络 | 需要先选定有意义的轴与排序规则 |

**力导向布局**（Fruchterman–Reingold、ForceAtlas2 等）把边当作弹簧、把节点之间当作斥力，寻找能量较低的位置。它的结果有两个经常被忽视的性质：第一，布局是随机初值上的局部最优，不同种子会给出不同的图；第二，两个节点在图上的距离只是近似反映图距离，**不能把“看起来靠得近”当作结论**。

**Hive plot**（Krzywinski 等，2012）针对这些问题提出“有规则的布局”：把节点按类别分配到若干条放射状的轴上，沿轴的位置由一个定量属性（如度）决定，边画成轴之间的曲线。同样的规则作用于两个网络，得到的图可以直接比较。**层次边捆绑**（Holten，2006）则把具有层次结构的连接沿层次树捆绑在一起，减少交叉，常用于环形的脑连接图（connectogram）。

### 视觉映射

1. **位置**最精确，**长度**次之，**面积、颜色饱和度**较差。最重要的变量用位置编码，其次才是节点大小或颜色。
2. **节点大小映射面积而不是半径**：若半径与度成正比，度增加一倍，面积增加三倍，视觉上夸大了枢纽。
3. **边的粗细与透明度**：加权网络中，粗细只适合少数几档；边很多时用透明度弱化弱边，并在图注中说明是否省略了某些边。
4. **标注**：只标注与结论相关的节点（候选基因、枢纽脑区），其余用颜色或图例概括。

### 常见错误

::: {.callout-warn}
**网络可视化中的常见错误**

1. **毛线团图当结论**：全网节点–链接图无法支持“存在模块”“存在枢纽”这类结论，结论应来自定量分析。
2. **为了好看而阈值化**：为了让图清楚，只画最强的 5% 的边，却在正文中把图上的结构当作发现。展示用的阈值应与分析用的阈值区分并在图注说明。
3. **组间比较使用不同布局**：患者组和对照组各自做一次力导向布局，位置不同，读者无法对照。应固定节点坐标（同一布局或解剖坐标）。
4. **布局不可复现**：未固定随机种子、未保存坐标。应保存节点坐标文件，或在代码中固定种子（如 `nx.spring_layout(G, seed=1)`）。
5. **把空间距离读成网络距离**：布局中两个模块靠得近，并不意味着它们之间连接多。
6. **颜色负担过重**：一张图里同时用颜色编码社团、组别、显著性。每种视觉通道只编码一个变量。
7. **3D 图与玻璃脑图过度使用**：三维图存在遮挡和透视变形；脑网络通常配合二维投影或矩阵图一起给出。
:::

### 生物医学中的常见图式

- **分子网络**：Cytoscape 是分子网络可视化的标准工具，可把表达量、突变频率等数据映射到节点属性；Merico 等（2009）总结了用网络解读组学数据时的布局与视觉映射要点。Gehlenborg 等（2010）与 O'Donoghue 等（2018）综述了组学和生物医学数据可视化的工具与原则。
- **基因组尺度关系**：Circos 环形图（Krzywinski 等，2009）适合展示染色体位置之间的关系（如结构变异、Hi-C 接触），但边过多时同样会退化为难以阅读的图。
- **脑网络**：常见做法是把节点放在解剖坐标上（玻璃脑投影）、按脑叶或功能系统排列的环形图，以及按功能系统排序的连接矩阵。比较组间差异时，矩阵图配合 NBS 等统计方法筛选出的子网络比全连接图更有信息量（见[组间比较与统计验证](brain-connectome.group-comparison.html)）。

::: {.callout-bio}
**同一网络，两种画法**：代码示例用种植分割模型生成 4 个社团、120 个节点的网络，并排画出力导向节点–链接图、随机排序的邻接矩阵和按 Louvain 社团排序的邻接矩阵。排序后的矩阵呈现清晰的对角块，块外的点就是社团间的边；随机排序的矩阵看不出任何结构；节点–链接图虽然也能看出团块，但团块的位置和形状随布局种子变化。这说明“能否看出结构”取决于呈现方式，而结构是否存在要靠模块度和零模型来判断（见[社团结构与社区发现](community-structure.validation.html)）。
:::

## 科学报告的结构与要点 {#report-structure}

### 报告的组成

一篇网络分析研究报告通常包含以下部分：

| 部分 | 要回答的问题 |
|---|---|
| 摘要 | 问题、数据、方法、主要发现、意义，各一两句 |
| 引言 | 生物医学背景是什么？为什么要用网络？研究问题和假设是什么？ |
| 方法 | 数据来源与版本、预处理、节点和边的定义、网络构建步骤、指标与算法、零模型、敏感性分析、软件与 AI 使用说明 |
| 结果 | 按研究问题组织；每个结果配图表，说明与什么比较 |
| 讨论 | 生物学解释、与文献比较、局限、替代解释、未来工作 |
| 结论 | 回答引言提出的问题 |
| 参考文献 | 每条可通过 DOI 或数据库核对 |

::: {.callout-def}
**“方法可复现”标准**：一位具备相关背景的研究者，只看你的方法部分（加上你提供的代码），就能从原始数据重新构建出同一个网络、算出同样的数值。数据库版本、阈值、随机种子、软件版本缺一不可。
:::

### 网络分析方法部分的报告要素

| 环节 | 需要写清的内容 | 相关页面 |
|---|---|---|
| 数据 | 来源数据库与版本号（如 STRING 版本、置信度阈值）、样本量、纳入排除标准 | [节点与边的定义](network-construction.nodes-and-edges.html) |
| 节点 | 节点代表什么（基因、蛋白、脑区、症状），图谱或基因标识符体系 | [脑图谱与节点定义](brain-connectome.parcellation.html) |
| 边 | 边的含义（物理相互作用、相关、偏相关、因果），有向/无向，加权/二值，估计方法 | [连接强度的估计](network-construction.edge-estimation.html) |
| 稀疏化 | 阈值类型（绝对、比例、统计显著性）与取值，是否在一个范围内重复分析 | [阈值、加权与稀疏化](network-construction.thresholding.html) |
| 指标与算法 | 指标的确切定义（加权还是二值版本）、算法与参数（如 Louvain 的 $\gamma$、随机种子、重复次数） | [网络结构指标与随机图](network-metrics.html) |
| 零模型 | 零模型类型（ER、度保持、空间约束、度匹配抽样）、随机网络数目、检验统计量 | [零模型与空模型](network-construction.null-models.html) |
| 统计 | 多重比较校正方法、效应量、置信区间 | [统计推断与多重比较](network-construction.statistical-inference.html) |
| 稳健性 | 改变阈值、图谱、数据库版本、算法后结论是否改变 | [敏感性分析与替代解释](reproducible-research.sensitivity-analysis.html) |
| 机器学习 | 训练/验证/测试划分方式（按节点、按边、按药物、按时间、按站点）、超参数选择、基线方法 | [图神经网络](reporting-frontiers.graph-neural-networks.html) |
| 可复现 | 代码与数据的公开位置、软件版本、运行环境 | [可复算的分析](reproducible-research.reproducible-analysis.html) |

### 报告自查清单

| 维度 | 自查问题 |
|---|---|
| 数据处理与分析的完整性 | 节点和边的定义有生物学依据吗？有零模型和敏感性分析吗？ |
| 结果呈现的准确性 | 每张图都有对照吗？数值与图表一致吗？ |
| 生物学解释的深度 | 解释有文献支持吗？考虑过替代解释吗？ |
| 写作的逻辑性和语言表达 | 每节都在回答引言的问题吗？术语前后一致吗？ |
| 创新性 | 与已有文献相比，新在哪里？ |

::: {.callout-warn}
方法的新颖性不能替代分析的扎实。一个问题朴素但方法扎实、对照完整、解释审慎的研究，通常比一个方法花哨却缺乏零模型和验证的研究更有说服力。
:::

### 口头报告

以 12 分钟的报告为例：

| 环节 | 时间 | 幻灯片 |
|---|---|---|
| 问题与动机 | 2 分钟 | 2 页：背景一句话 + 研究问题 |
| 数据与方法 | 3 分钟 | 2–3 页：一张流程图胜过多页文字 |
| 主要结果 | 5 分钟 | 3–4 页：每页一个结论 |
| 局限与结论 | 2 分钟 | 1–2 页：带回研究问题 |

1. **先讲结论**：开场 1 分钟内让听众知道你要证明什么。
2. **一页一个信息**：幻灯片标题写成一句完整的结论。
3. **讲图不读字**：指着图告诉听众看哪里——“红线是疾病基因，灰色分布是随机基线”。
4. **主动讲局限**：在被问到之前说出最重要的一两个局限，以及你做了什么来检验它们。
5. **准备备用页**：把敏感性分析、补充图放在附录页，回答提问时调出。

### 审阅一项网络分析研究

审阅他人的网络分析（例如作为期刊审稿人）时，一份好的审阅意见包括：

1. **一句话复述**：用自己的话写出该研究的问题和主要结论。复述不出来，往往说明报告的逻辑需要改进，这本身就是有用的反馈。
2. **主要意见**（1–3 条）：影响结论成立的问题，例如缺少零模型、混杂因素未处理、结论超出证据。
3. **次要意见**：图表、表述、引用格式等。
4. **具体建议**：每条主要意见都附一个可行的改进办法。

审阅网络分析时最值得追问的几件事：节点和边的定义是否与研究问题匹配；比较的两个网络密度是否相同；零模型是否保留了应保留的性质（度、空间嵌入、数据库的研究偏倚）；结论是否依赖某个特定阈值或参数；机器学习研究的测试集是否与训练集独立。

::: {.callout-def}
**区分“结论错了”与“证据不足”**：审阅时最常见的有效意见不是“你的结论是错的”，而是“现有分析还不足以支持这个结论，需要补充某项对照或检验”。前者需要你有反证，后者只需要指出逻辑缺口。
:::

::: {.callout-def}
**有依据的审阅意见**：指出问题时说明理由，并尽量提出可检验的改进办法；评价分析和论证，而不是评价人。“这个结果不可信”不是有用的意见；“该结论可能受两组网络密度不同的影响，建议在相同密度下重新比较”是。
:::

作为作者回应审阅意见时，通常附一份修改说明：逐条列出收到的意见、你的回应（采纳、部分采纳或不采纳及理由）以及对应修改在文中的位置。

**主线四：网络是构建出来的。** [脑连接组](brain-connectome.html)中的阈值与图谱、[症状网络](symptom-networks.html)中的偏相关与正则化、[基因调控网络推断](gene-network-inference.html)：边的定义决定了你能回答什么问题。[网络构建与统计验证](network-construction.html)与[敏感性分析与替代解释](reproducible-research.sensitivity-analysis.html)是对这一点的系统回应。

这五条主线在前沿方向中依然成立，只是换了形式：高阶网络中“度”推广为超度和单纯形的维数，“零模型”推广为保持超边大小分布的随机超图；时间网络的零模型是打乱时间戳；多层网络中的“模块”需要决定层间耦合强度；图神经网络中“与什么比较”就是与简单基线和合理的数据划分比较。

::: {.callout-bio}
用一个例子把五条主线串起来：研究某种神经退行性疾病时，你可以（1）从 STRING 构建 PPI 网络，检验疾病基因是否形成显著模块（主线二、五）；（2）用患者脑组织表达谱做 WGCNA，看疾病模块是否在共表达层面重现（主线二、四）；（3）计算候选药物靶点与疾病模块的邻近度（主线一、五）；（4）在患者脑影像中检验相关脑区的枢纽地位是否改变（主线一、四）。每一步都要写清“与什么比较”和“换个选择结论是否改变”。
:::

## 高阶相互作用：超图与单纯复形 {#higher-order}

### 为什么需要高阶表示

普通网络只表示两两关系，而许多生物过程涉及三个以上元素同时作用：多个亚基组成的蛋白复合物、多底物多产物的代谢反应、多个转录因子共同调控一个基因、多个脑区的协同激活、多种药物联用产生的相互作用。把这样的群体作用拆成两两边（“投影”）会丢失信息：**一个三元复合物 $\{a,b,c\}$ 和三对两两结合 $\{a,b\},\{b,c\},\{a,c\}$ 投影后是同一张三角形图**。Klamt 等（2009）以代谢和信号网络为例论证了超图在细胞网络建模中的必要性；Battiston 等（2020）的综述系统总结了高阶相互作用的表示方法、结构指标和动力学后果。

::: {.callout-def}
**超图（hypergraph）**：$H=(V,E)$，其中每条**超边** $e\in E$ 是节点集 $V$ 的任意非空子集，大小 $|e|$ 可以是 2、3 或更多。用**关联矩阵** $I\in\{0,1\}^{N\times M}$ 表示：$I_{ie}=1$ 当且仅当节点 $i$ 属于超边 $e$。

- 节点 $i$ 的**超度** $k_i^{H}=\sum_e I_{ie}$：所在超边的数目；
- 超边大小 $|e|=\sum_i I_{ie}$；
- **两两投影**（clique expansion）：$W = I I^{\top} - \mathrm{diag}(k^{H})$，$W_{ij}$ 是 $i,j$ 共同出现的超边数。投影丢失了“哪些节点同时出现在一条超边里”的信息。
:::

::: {.callout-def}
**单纯复形（simplicial complex）**：一组单纯形的集合，$k$-单纯形是由 $k+1$ 个节点构成的集合（0-单纯形是节点，1-单纯形是边，2-单纯形是实心三角形，3-单纯形是实心四面体），并且满足**向下封闭**：若一个单纯形属于复形，它的所有面（子集）也属于复形。超图不要求向下封闭，因此更灵活；单纯复形的封闭性则让它可以使用代数拓扑工具（边界算子、同调、霍奇理论）。

**团复形（clique complex）**：把一个普通网络中每个 $(k+1)$-团都填成 $k$-单纯形得到的单纯复形。它是从两两数据构造高阶对象最常用的方法，但要注意：团复形里的高阶结构完全由两两边决定，并不包含新的群体相互作用信息。
:::

### 边界算子与霍奇拉普拉斯

给每个单纯形规定一个顶点顺序（定向）。**边界算子** $B_k$ 把 $k$-单纯形映射到它的 $(k-1)$-维面上的带符号组合，例如

$$
\partial[a,b,c]=[b,c]-[a,c]+[a,b],\qquad \partial[a,b]=b-a .
$$

$B_1$ 是“节点 × 边”的有向关联矩阵，$B_2$ 是“边 × 三角形”矩阵，且**边界的边界为零**：$B_1B_2=0$。由此定义第 $k$ 阶**霍奇拉普拉斯**

$$
L_0=B_1B_1^{\top},\qquad L_k=B_k^{\top}B_k+B_{k+1}B_{k+1}^{\top}\quad(k\ge1),
$$

其中 $L_0$ 正是普通的图拉普拉斯 $D-A$。$L_k$ 的零空间维数等于第 $k$ 个**贝蒂数** $\beta_k$：$\beta_0$ 是连通分支数，$\beta_1$ 是没有被三角形“填满”的独立环的数目，$\beta_2$ 是空腔数。也可以用秩计算：

$$
\beta_k=\dim\ker B_k-\operatorname{rank}B_{k+1}=n_k-\operatorname{rank}B_k-\operatorname{rank}B_{k+1}.
$$

### 算例：空心三角形与实心三角形

三个节点 $0,1,2$ 和三条边 $[0,1],[0,2],[1,2]$：

$$
B_1=\begin{pmatrix}-1&-1&0\\ 1&0&-1\\ 0&1&1\end{pmatrix},\quad \operatorname{rank}B_1=2 .
$$

- **空心三角形**（没有 2-单纯形）：$\beta_0=3-2=1$，$\beta_1=3-2-0=1$——有一个一维“洞”。
- **实心三角形**（加入 $[0,1,2]$）：$B_2=(1,-1,1)^{\top}$，秩为 1，$\beta_1=3-2-1=0$——洞被填上。

验证欧拉示性数：$\chi=n_0-n_1+n_2=\beta_0-\beta_1+\beta_2$，空心时 $3-3+0=1-1$，实心时 $3-3+1=1-0$。这两种结构在两两网络中完全相同，区别只在于“三人是两两认识，还是同属一个群体”。[代码示例](reporting-frontiers.html#code)用矩阵秩和 $L_1$ 的零空间验证了这个算例。

### 高阶相互作用的动力学后果

高阶表示的意义不只是描述得更准确，而是**动力学行为会发生质变**：

- **传播**：Iacopini 等（2019）提出单纯复形上的传染模型——节点除了经由边被感染，还可以在一个 2-单纯形的另外两个节点都已感染时以额外概率被感染。当三体感染率足够大时，流行病转变从连续变为**不连续（爆发式）**，并出现**双稳态**：初始感染比例不同，最终状态不同。这对应社会行为传播中“需要多个接触者同时强化”的复杂传染（见[网络上的传播与免疫](spreading.frontiers.html)）。
- **同步**：Skardal 与 Arenas（2019）在含三体耦合的振子系统中发现突然的去同步和大量多稳态（见[同步与协同动力学](synchronization.html)）。
- **扩散与共识**：在单纯复形上，信号不仅能沿节点扩散，也能沿边、沿三角形扩散，由相应阶的霍奇拉普拉斯刻画，可用于分析边上的流（如通量、信息流）。

### 高阶结构的统计检验与零模型

与普通网络一样，“存在高阶结构”的结论需要零模型：常用的是保持节点超度和超边大小分布的随机超图（超边端点重连），或保持两两投影不变、随机化三元组的模型。Benson、Gleich 与 Leskovec（2016）提出的基于基序的谱聚类则是另一条路线：先统计某种小子图（如三角形、双扇形）的共同参与次数，构造“基序邻接矩阵”，再做聚类，把“哪些节点一起参与高阶模式”作为社团的定义。

::: {.callout-bio}
**生物医学中的高阶数据**：蛋白复合物数据库（如 CORUM）天然就是超图——每个复合物是一条超边；代谢网络中一个反应连接多个底物和产物，是有向超图；药物联用的副作用是“药物对或药物组合”的属性；共病数据中一个患者同时患有的多种疾病构成一条超边。把这些数据投影成两两网络再分析，会把“同时出现”混同为“两两关联”。问题是否需要高阶表示，取决于研究问题是否涉及群体作用本身（Torres 等，2021）。
:::

::: {.callout-warn}
**高阶表示的常见陷阱**：（1）用团复形把普通网络“升级”为单纯复形，得到的高阶结构并不比原网络包含更多信息；（2）高阶相互作用往往是从两两相关或共现中推断出来的，“三个变量共同出现”不等于存在不可分解的三体作用，统计上需要检验高阶项是否显著；（3）超边数目随规模组合增长，计算与多重比较负担都更重。Bick 等（2023）讨论了什么时候真的需要高阶网络。
:::

## 拓扑数据分析与持续同调入门 {#topological-data-analysis}

### 思想

很多网络分析需要先选一个阈值把加权网络变成二值网络，而结论常常随阈值改变（见[阈值、加权与稀疏化](network-construction.thresholding.html)）。**拓扑数据分析**（topological data analysis, TDA；Carlsson，2009）换了一个角度：不选单一阈值，而是**记录拓扑特征在全部阈值上的出现与消失**。

::: {.callout-def}
**过滤（filtration）**：一列嵌套的单纯复形 $K_1\subseteq K_2\subseteq\cdots\subseteq K_T$。对加权网络，常见做法是按边权从大到小依次加入边，每一步取团复形。

**持续同调（persistent homology）**：追踪每个拓扑特征（连通分支、环、空腔）在哪一步**出生**、哪一步**死亡**（被合并或被填满）。结果可以表示为：

- **条形码（barcode）**：每个特征一条从出生到死亡的线段；
- **持续图（persistence diagram）**：以（出生，死亡）为坐标的点集，离对角线越远的点越持久；
- **贝蒂曲线**：$\beta_k$ 随过滤参数（如边密度）的变化曲线。
:::

直观理解：持续时间很短的特征通常是噪声，持续时间长的特征反映数据的稳健结构。$\beta_0$ 的条形码等价于单链接层次聚类的树状图；$\beta_1$ 则捕捉“环”——在网络中表示一组节点两两相连成圈、但内部缺少把它填满的三角形。

### 算例：环状几何网络

把 16 个节点等距排在圆周上，边权随圆周距离衰减。按边权从大到小加入边：开始时只有相邻节点相连，很快形成一个绕圆周的大环（$\beta_1=1$），环内部缺少跨越圆周的边，所以这个环在一个较宽的密度区间内持续存在；当密度足够大、跨越圆周的边和三角形填满环时，$\beta_1$ 回到 0。把边权随机打乱后，$\beta_1$ 会在较低密度出现多个短暂的环，而不是一个持续的大环。[代码示例](reporting-frontiers.html#code)画出了两者的贝蒂曲线。

### 在神经科学中的应用

- Giusti 等（2015）分析大鼠海马神经元活动的相关矩阵，按相关强度排序构造团复形过滤，提出“团拓扑”（clique topology）方法：它只依赖相关值的排序，因此对单调非线性变换不变；用这种方法，仅凭神经活动本身、不借助外部刺激或感受野信息，就检测到了相关结构中的几何组织。
- Petri 等（2014）提出“同调骨架”（homological scaffold），把持续的一维环投影回边上，用于比较功能连接网络在不同状态（安慰剂与裸盖菇素）下的拓扑差异。
- Sizemore 等（2018）在人脑结构连接组中寻找最大团和持续同调意义下的“空腔”，讨论它们在脑区间信息处理中的可能角色。

::: {.callout-warn}
**TDA 的局限**：（1）贝蒂数是全局量，难以直接对应到具体的生物学机制；（2）计算高阶同调的代价随单纯形数目迅速增长，大网络通常只算到 $\beta_1$ 或 $\beta_2$；（3）持续图之间的统计比较需要专门的方法（如置换检验、持续景观），不能只看图像差异；（4）与其他网络指标一样，结论要和合适的零模型（随机权重、随机几何模型）比较。
:::

## 时间网络 {#temporal-networks}

### 从静态网络到时间网络

许多生物医学网络中，边只在特定时刻存在：医院里医护人员与患者的接触、性接触网络、动物个体间的接触、神经元之间的放电序列、症状随日常生活的波动。把所有接触累加成一张静态的**聚合网络**，会丢失两类关键信息：**接触的先后顺序**与**接触的时间间隔分布**。Holme 与 Saramäki（2012）的综述系统建立了时间网络的表示、指标与零模型；Holme（2015）给出了较新的进展概览。

::: {.callout-def}
**接触序列（contact sequence）**：三元组 $(u,v,t)$ 的列表，表示 $u$ 与 $v$ 在时刻 $t$ 接触（持续时间可忽略）；若接触有持续时间，则用**区间图**（interval graph）$(u,v,t_{\text{start}},t_{\text{end}})$。

**时间一致路径（time-respecting path）**：一串接触 $(v_0,v_1,t_1),(v_1,v_2,t_2),\dots$，满足 $t_1\le t_2\le\cdots$（可加最大等待时间限制）。只有沿时间一致路径，传染或信息才能从 $v_0$ 到达终点。

**可达集与延迟**：$i$ 在时刻 $t$ 之后能沿时间一致路径到达的节点集合；最早到达所需的时间称为**延迟**（latency）或时间距离。
:::

### 算例：时间顺序破坏对称性

三个节点 A、B、C，接触为 $(A,B,t=1)$、$(B,C,t=2)$。

- 从 A 出发：$t=1$ 传给 B，$t=2$ B 传给 C，**A 能到达 C**。
- 从 C 出发：$t=2$ 才与 B 接触，而 B 与 A 的接触发生在 $t=1$，已经过去，**C 不能到达 A**。

聚合网络是无向路径 A–B–C，认为两个方向都可达。时间网络中，可达性**不对称、不传递**（A 能到 B、B 能到 C，不意味着 A 能到 C；这取决于时间顺序）。因此聚合网络通常会**高估**传播可达范围。

### 阵发性与时间相关

真实接触的间隔往往不是指数分布（泊松过程），而是大量短间隔夹杂少量很长的空窗，称为**阵发性**（burstiness）。Goh 与 Barabási（2008）提出的阵发性系数

$$
B=\frac{\sigma_\tau-\mu_\tau}{\sigma_\tau+\mu_\tau}\in[-1,1],
$$

其中 $\mu_\tau,\sigma_\tau$ 是接触间隔的均值与标准差：完全周期时 $B=-1$，泊松过程 $B=0$，强阵发性时 $B\to1$。阵发性一般会**减慢**传播，因为传染者可能在长空窗中恢复。

接触的顺序还可能带有**记忆**：经过 B 的路径更可能从 A 到 C 而不是从 A 回到 A。Scholtes 等（2014）表明，这种非马尔可夫的顺序相关可以使扩散相对于聚合网络的预测显著变慢或变快，并用二阶聚合网络（以边为节点、以两步路径为边）来刻画；Lambiotte、Rosvall 与 Scholtes（2019）把它推广为在不同阶的路径模型之间做统计选择。

### 零模型：随机化参照模型

时间网络的“与什么比较”是一系列逐级破坏时间结构的随机化：

| 随机化 | 保留 | 破坏 | 用来检验 |
|---|---|---|---|
| 打乱时间戳 | 谁与谁接触、每对的接触次数、总体活动的时间分布 | 接触顺序、每对接触的时间相关 | 时间顺序本身是否重要 |
| 随机化每对的接触时间（均匀分布） | 静态网络、每对接触次数 | 阵发性、日周期 | 阵发性的作用 |
| 在聚合网络上重连 | 时间序列、度 | 拓扑 | 拓扑的作用 |

[代码示例](reporting-frontiers.html#code)用模拟接触数据比较聚合网络、原始时间网络和打乱时间戳后的可达节点对比例，并计算阵发性系数。

::: {.callout-bio}
**医院接触网络**：Vanhems 等（2013）用可穿戴近距离传感器记录了一家医院老年病房中患者与医护人员之间的接触，分析了不同职业类别之间的接触结构，讨论了医院内感染可能的传播途径。这类数据的时间结构（交接班、查房时段）决定了干预应在何时、对谁实施——这是聚合网络回答不了的问题。
:::

::: {.callout-warn}
时间网络分析结论对时间分辨率敏感：时间窗太粗会把先后发生的接触当成同时发生，太细则网络过于稀疏。传感器数据还存在覆盖不全（并非所有人都佩戴）和距离阈值设定问题。脑网络中的“时间网络”（滑动窗口功能连接）有其特殊的统计问题，见[动态功能连接与多层脑网络](dynamic-brain-networks.html)；个体症状的时间网络见[个体动态网络](symptom-networks.temporal-networks.html)。
:::

## 多层与相互依赖网络 {#multilayer-networks}

### 统一框架

当同一组实体之间存在多种关系（PPI、共表达、遗传相互作用），或多组实体之间存在跨类型的关系（基因–蛋白–代谢物–疾病），或网络随时间改变时，可以把它们放在一个**多层网络**中。Kivelä 等（2014）给出了统一的数学框架和术语；De Domenico 等（2013）用张量形式化；Boccaletti 等（2014）综述了结构与动力学；Bianconi 的专著《Multilayer Networks》（2018）系统讲解了多层网络的结构、渗流与扩散理论。

::: {.callout-def}
**多层网络**：节点–层二元组 $(i,\alpha)$ 的集合，边连接 $(i,\alpha)$ 与 $(j,\beta)$。$\alpha=\beta$ 的是**层内边**，$\alpha\ne\beta$ 的是**层间边**。常见特例：

- **多重网络（multiplex）**：各层节点相同，层间边只连接同一节点在不同层的副本（如同一组基因的 PPI 层、共表达层、通路层；同一组脑区的结构层与功能层）；
- **时间多层网络**：每层是一个时间窗，层间边连接相邻时间窗的同一节点；
- **相互依赖网络（interdependent networks）**：不同层是不同实体，层间边表示**依赖**——一层节点失效会导致其依赖的另一层节点失效。

**超邻接矩阵（supra-adjacency）**：把 $L$ 层、每层 $N$ 个节点的多重网络写成 $NL\times NL$ 的分块矩阵，对角块是各层邻接矩阵，非对角块是层间耦合。
:::

### 多重网络的结构指标

- **边重叠**：两层共享的边比例，衡量两种关系是否冗余；
- **节点在各层的度向量** $(k_i^{[1]},\dots,k_i^{[L]})$ 与**多重参与系数**（Battiston、Nicosia 与 Latora，2014）：

$$
P_i=\frac{L}{L-1}\Big[1-\sum_{\alpha=1}^{L}\Big(\frac{k_i^{[\alpha]}}{o_i}\Big)^2\Big],\qquad o_i=\sum_\alpha k_i^{[\alpha]},
$$

$P_i$ 接近 1 表示节点的连接均匀分布在各层，接近 0 表示集中于某一层。
- **多层模块度**：Mucha 等（2010）的推广，层间耦合 $\omega$ 控制各层划分的一致性，详见[多层网络](dynamic-brain-networks.multilayer.html)。

### 多层网络上的扩散

两层多重网络、层间扩散系数为 $D_x$ 时，**超拉普拉斯矩阵**为

$$
\mathcal{L}=\begin{pmatrix}L^{[1]}+D_xI & -D_xI\\ -D_xI & L^{[2]}+D_xI\end{pmatrix}.
$$

扩散趋于平衡的时间尺度由其第二小特征值 $\lambda_2(\mathcal{L})$ 决定。Gómez 等（2013）指出两个极限：

- $D_x$ 很小时，$\lambda_2\approx 2D_x$：慢模式是两层之间的整体交换。向量 $x=(\mathbf{1},-\mathbf{1})$ 恰好是特征值为 $2D_x$ 的特征向量（推导见[数学推导与算法](reporting-frontiers.derivations.html)）。
- $D_x$ 很大时，$\lambda_2(\mathcal{L})\to\lambda_2\big((L^{[1]}+L^{[2]})/2\big)$，可以大于任一单层的 $\lambda_2$，即多层上的扩散比在任一单层上都快（**超扩散**）。

[代码示例](reporting-frontiers.html#code)在一个 ER 层与一个小世界层组成的多重网络上画出 $\lambda_2$ 随 $D_x$ 的变化。

### 相互依赖网络与级联失效

Buldyrev 等（2010）研究两个相互依赖的网络：A 层节点失效使其依赖的 B 层节点失效，B 层失效又反过来影响 A 层，如此迭代。与单个网络的连续渗流转变不同，相互依赖网络的崩溃是**不连续的一阶转变**——移除节点的比例稍过临界点，巨连通分支就突然消失；而且在单层网络中能提高抗随机失效能力的宽度分布，在相互依赖时反而让系统更脆弱。这一框架常被用来讨论电网–通信网、器官系统之间的依赖（论文精读见 [Buldyrev 2010](paper-buldyrev2010_cascade.html)；渗流理论见[网络鲁棒性、渗流与级联失效](robustness.html)）。

::: {.callout-bio}
**多层网络在生物医学中的例子**

- **疾病多重网络**：Halu 等（2019）把基于共享基因的疾病关系与基于共享症状的疾病关系作为两层，研究基因型与表型两种疾病相似性在网络结构上的异同。
- **多重网络上的随机游走**：Valdeolivas 等（2019）把带重启的随机游走推广到多重网络（如 PPI、通路、共表达层）以及与疾病相似性网络相连的异质网络，用于候选疾病基因排序；它是[网络医学](network-medicine.html)中网络扩散方法的多层版本。
- **脑网络**：结构–功能多层网络、频段多层网络（不同频段的 MEG 连接作为不同层）以及时间多层网络，综述见 De Domenico（2017）。
- **多组学整合**：基因组、转录组、蛋白组、代谢组与临床表型放在不同层中，用层间边连接对应实体；生物医学知识图谱（见[异质网络、知识图谱与图机器学习](network-medicine.knowledge-graphs.html)）可视为节点类型和边类型都很多的多层网络。
:::

::: {.callout-warn}
**多层分析的常见问题**：（1）层间边的权重（$\omega$、$D_x$）通常没有实测依据，结论应在一个参数范围内检查；（2）各层的数据质量和覆盖率不同（如 PPI 层偏向被深入研究的蛋白），直接合并会让高覆盖层主导结果；（3）先把多层压成一层（聚合）再分析，往往会丢失恰恰需要的信息，应与多层分析结果比较；（4）层数增加时零模型也要多层化，例如在每层内分别做度保持重连，或打乱层间对应关系。
:::

## 网络表示学习：谱嵌入与随机游走嵌入 {#network-embedding}

### 编码器–解码器框架

**网络嵌入**（network embedding，图表示学习）把每个节点 $v$ 映射为一个低维向量 $z_v\in\mathbb{R}^d$，使得向量之间的几何关系（内积、距离）反映网络中的关系（邻接、多步可达、结构角色）。Hamilton（2020）用统一的**编码器–解码器**框架描述这类方法：

- **编码器** $\mathrm{ENC}(v)=z_v$：对“浅层嵌入”就是查表，每个节点一个自由参数向量；
- **解码器** $\mathrm{DEC}(z_u,z_v)$：给出一个相似度估计，例如内积 $z_u^{\top}z_v$；
- **目标**：让 $\mathrm{DEC}(z_u,z_v)$ 逼近某个网络相似度 $S[u,v]$（邻接、共同邻居数、随机游走共现概率等）。

不同方法的差别主要在于选择哪个 $S$ 和哪个损失函数。

### 谱嵌入：拉普拉斯特征映射

Belkin 与 Niyogi（2003）的**拉普拉斯特征映射**要求相连节点的嵌入彼此接近：

$$
\min_{Y}\ \sum_{i,j}W_{ij}\,\|y_i-y_j\|^2=2\,\mathrm{tr}(Y^{\top}LY)\quad\text{s.t.}\quad Y^{\top}DY=I .
$$

约束排除了全部节点坍缩到同一点的平凡解。拉格朗日条件给出广义特征值问题 $Ly=\lambda Dy$，取除常向量外最小的 $d$ 个特征向量作为坐标。它与谱聚类（见[谱方法与层次聚类](community-structure.spectral-hierarchical.html)）同源：Fiedler 向量就是一维的拉普拉斯嵌入。谱嵌入是确定性的、可解释的，但只编码一阶邻近关系，且对大规模网络需要稀疏特征值求解。

### 随机游走嵌入：DeepWalk 与 node2vec

**DeepWalk**（Perozzi 等，2014）把网络上的截断随机游走当作“句子”、节点当作“词”，用自然语言处理中的 skip-gram 模型学习嵌入：在同一游走中、窗口距离不超过 $w$ 的节点对被视为“共现”，目标是让共现节点的内积大、随机负样本的内积小。带负采样的目标函数为

$$
\max\ \sum_{(u,v)\in\mathcal{D}}\Big[\log\sigma(z_u^{\top}z_v)+k\,\mathbb{E}_{n\sim P_{\text{neg}}}\log\sigma(-z_u^{\top}z_n)\Big].
$$

**node2vec**（Grover 与 Leskovec，2016）把游走改为二阶有偏随机游走：从 $t$ 刚走到 $v$，下一步走向 $v$ 的邻居 $x$ 的非归一化概率为 $\pi_{vx}=\alpha_{pq}(t,x)\,w_{vx}$，

$$
\alpha_{pq}(t,x)=\begin{cases}1/p, & d_{tx}=0\ (\text{回到 } t)\\ 1, & d_{tx}=1\ (x \text{ 与 } t \text{ 相邻})\\ 1/q, & d_{tx}=2\end{cases}
$$

返回参数 $p$ 控制折返的倾向；进出参数 $q$ 控制向外探索的倾向：$q<1$ 时游走更像深度优先，倾向于捕捉社团（同质性）；$q>1$ 时更像广度优先，停留在局部，倾向于捕捉结构角色。

**算例**：游走从 $t$ 走到 $v$，$v$ 的邻居为 $t$、$x_1$（与 $t$ 相邻）、$x_2$（与 $t$ 不相邻），无权网络，$p=1,q=0.5$。非归一化概率依次为 $1,1,2$，归一化后为 $0.25,0.25,0.5$：游走更可能离开 $t$ 的邻域。

### 嵌入即矩阵分解

Qiu 等（2018）证明，DeepWalk 在负采样下隐式地分解一个矩阵，近似为

$$
\log\Big(\frac{\mathrm{vol}(G)}{bT}\Big(\sum_{r=1}^{T}(D^{-1}A)^r\Big)D^{-1}\Big),
$$

其中 $T$ 是窗口大小、$b$ 是负样本数、$\mathrm{vol}(G)=\sum_i d_i$。也就是说，随机游走嵌入本质上是对“多步转移概率”做对数变换后的低秩分解，与谱方法属于同一家族。[代码示例](reporting-frontiers.html#code)就用“随机游走共现矩阵 → 正点互信息（PPMI）→ 截断 SVD”实现了一个 node2vec 式嵌入，避免依赖深度学习库。

### 浅层嵌入的局限

1. **转导式**：只能为训练时见过的节点产生嵌入，新加入的节点（新药、新患者）需要重新训练；
2. **不使用节点特征**：基因表达、分子结构、影像特征等信息无法自然纳入；
3. **参数随节点数线性增长**，不同节点之间不共享参数；
4. **嵌入的坐标没有直接含义**，且不同次训练得到的嵌入只在旋转意义下等价，不能跨次比较坐标。

这些局限正是图神经网络的动机。对多关系的知识图谱，还有专门的嵌入方法（把关系建模为向量空间中的平移或双线性变换），见 Hamilton（2020）第 4 章。

::: {.callout-bio}
**生物医学网络嵌入的评估**：Yue 等（2020）选取 11 种代表性的嵌入方法（矩阵分解类、随机游走类与神经网络类），在 3 个生物医学链接预测任务（药物–疾病关联、药物–药物相互作用、蛋白质相互作用）和 2 个节点分类任务上做了系统比较，结论是较新的嵌入方法在这些任务上有竞争力、值得在生物医学网络分析中进一步使用。这类基准研究的价值主要在于提供统一的数据划分与评估流程；对自己的数据，仍需在相同划分下与简单基线比较。
:::

::: {.callout-warn}
**链接预测评估中的泄漏**：用于测试的边必须在学习嵌入**之前**从网络中移除，否则模型在训练时就“看到”了答案。负样本的选取也会影响结果：从全部非边中随机抽取的负样本大多是两个低度节点之间的“容易的负例”，会高估性能。代码示例在空手道网络上做了 10 次随机划分，比较谱嵌入、node2vec 式嵌入与共同邻居、Adamic–Adar 两个无需训练的基线，结果显示它们的差距小于划分之间的波动——在小网络上，简单基线往往同样有效。
:::

## 图神经网络 {#graph-neural-networks}

### 消息传递框架

**图神经网络（graph neural network, GNN）**通过在邻居之间反复“传递消息”学习节点、边或整张图的表示。与浅层嵌入不同，GNN 的参数在所有节点间共享，可以使用节点和边的特征，并能对训练时未见过的节点或新的图做预测（归纳式学习）。大多数 GNN 可以写成**消息传递**的形式：第 $l$ 层中，节点 $v$ 的表示 $h_v^{(l)}$ 更新为

$$
h_v^{(l+1)}=\mathrm{UPDATE}^{(l)}\Big(h_v^{(l)},\ \mathrm{AGG}^{(l)}\big(\{\mathrm{MSG}^{(l)}(h_v^{(l)},h_u^{(l)},e_{uv}):u\in\mathcal{N}(v)\}\big)\Big),
$$

其中 AGG 是对邻居顺序不敏感的聚合（求和、平均、最大值、注意力加权）。$L$ 层之后，每个节点的表示汇集了它 $L$ 步邻域内的信息。做**图级任务**（如分子性质预测、按脑网络分类被试）时，再用一个读出（readout）函数把所有节点表示汇总成整张图的表示。

### 几种代表性模型

| 模型 | 聚合方式 | 特点 |
|---|---|---|
| GCN（Kipf 与 Welling，2017） | $H^{(l+1)}=\sigma(\hat{A}H^{(l)}W^{(l)})$，$\hat{A}=\tilde{D}^{-1/2}(A+I)\tilde{D}^{-1/2}$ | 对称归一化的邻居平均；可由谱图卷积的一阶近似推出（见[数学推导与算法](reporting-frontiers.derivations.html)） |
| GraphSAGE（Hamilton 等，2017） | 采样固定数目的邻居，自身表示与邻居聚合结果拼接 | 归纳式，适合大图与新节点 |
| GAT（Veličković 等，2018） | 用注意力系数 $\alpha_{uv}$ 对邻居加权 | 不同邻居的贡献可学习 |
| GIN（Xu 等，2019） | $h_v\leftarrow\mathrm{MLP}\big((1+\epsilon)h_v+\sum_{u}h_u\big)$ | 求和聚合 + 多层感知机，区分能力达到 1-WL 检验的上限 |
| MPNN（Gilmer 等，2017） | 消息函数依赖边特征 | 分子图（原子为节点、化学键为边）上的通用框架 |

**算例：GCN 的传播矩阵**。路径图 $1-2-3$ 加自环后度为 $\tilde{d}=(2,3,2)$，于是

$$
\hat{A}=\begin{pmatrix}1/2 & 1/\sqrt6 & 0\\ 1/\sqrt6 & 1/3 & 1/\sqrt6\\ 0 & 1/\sqrt6 & 1/2\end{pmatrix}\approx\begin{pmatrix}0.50&0.41&0\\0.41&0.33&0.41\\0&0.41&0.50\end{pmatrix}.
$$

若只有节点 1 带特征 $x=(1,0,0)^{\top}$，一层传播后 $\hat{A}x\approx(0.50,0.41,0)$：信息到达了一步邻居；两层后才到达节点 3。

### 表达能力与过平滑

- **表达能力**：Xu 等（2019）证明，消息传递 GNN 区分两张图的能力不超过 1 维 Weisfeiler–Lehman（1-WL）图同构检验。例如两个三角形与一个六元环，每个节点度都是 2，1-WL 与标准消息传递 GNN 都无法区分；而在分子中，环的大小与化学性质密切相关。加入子结构计数、高阶 GNN 或位置编码是常见的改进方向。
- **过平滑（over-smoothing）**：Li 等（2018）指出，GCN 的图卷积本质上是一种拉普拉斯平滑。$\hat{A}$ 的最大特征值为 1，对应特征向量与 $\sqrt{\tilde d}$ 成正比，其余特征值绝对值小于 1，所以 $\hat{A}^kX$ 随 $k$ 增大收敛到只由度决定的秩 1 结构，节点之间可区分的信息指数衰减。这是 GCN 一般只用 2–3 层的原因。[代码示例](reporting-frontiers.html#code)直接展示了这一衰减。
- **过度挤压（over-squashing）**：远距离节点的信息要经过少数“瓶颈”边压缩到固定维度的向量里，长程依赖难以学习。

### 生物医学中的应用

::: {.callout-bio}
**药物组合副作用**：Decagon（Zitnik、Agrawal 与 Leskovec，2018）构建蛋白–蛋白、药物–靶点和药物–药物三类关系组成的多模态图，其中每一种多药联用副作用是一种不同类型的药物–药物边，用面向多关系链接预测的图卷积网络预测某一对药物会引起哪种副作用。它代表了把[网络药理学](network-medicine.network-pharmacology.html)中的异质网络转化为端到端学习问题的思路。
:::

::: {.callout-bio}
**分子与抗生素发现**：把分子表示为图（原子为节点、化学键为边），用消息传递网络预测分子性质。Stokes 等（2020）用这类有向消息传递神经网络学习化合物对大肠杆菌的生长抑制，在大规模化合物库中筛选，发现了结构上不同于已知抗生素的候选分子 halicin，并做了实验验证。这一例子的关键不在模型本身，而在“模型预测 → 湿实验验证”的闭环。
:::

::: {.callout-bio}
**蛋白质结构与功能**：DeepFRI（Gligorijević 等，2021）以蛋白质的残基接触图为图、以蛋白质语言模型提取的序列特征为节点特征，用图卷积网络预测基因本体（GO）功能和酶分类号；用类激活映射可以把预测定位到残基水平。AlphaFold2（Jumper 等，2021）把结构预测看作三维空间中的图推断问题，其 Evoformer 模块在残基对表示上进行基于三角形关系的更新——虽然它不是标准的 GNN，但体现了“在残基关系图上迭代推理”的思想。
:::

::: {.callout-bio}
**脑网络分类**：BrainNetCNN（Kawahara 等，2017）为连接矩阵设计了边到边、边到节点的卷积滤波器，用早产儿的弥散 MRI 结构连接组预测神经发育结局；BrainGNN（Li 等，2021）在 fMRI 功能连接图上使用脑区感知的图卷积和脑区选择池化，在自闭症谱系障碍等分类任务中同时给出与分类相关的脑区。这类研究面临的主要问题是样本量（通常为数百到数千名被试）、扫描站点效应以及与简单模型（如对连接矩阵上三角做正则化线性模型）的比较。
:::

更系统的综述见：Zitnik 等（2019）关于整合多种生物医学数据的机器学习原则；Gaudelet 等（2021）关于图机器学习在药物发现中的应用；Li、Huang 与 Zitnik（2022）关于生物医学与医疗中的图表示学习。

### 局限与评估要点

::: {.callout-warn}
**GNN 研究的常见问题**

1. **数据划分与泄漏**：链接预测中按边随机划分时，测试药物的近似药物（或同一药物的其他边）已在训练集中，性能被高估。应根据应用场景采用更严格的划分：按药物或按蛋白划分（冷启动）、按分子骨架划分、按时间划分（用早期数据训练、预测后来发现的关系）、按站点划分（脑影像）。
2. **研究偏倚**：知识图谱和 PPI 网络中被深入研究的节点连边多，模型可能学到“热门程度”而不是机制；应与度基线（只按节点度打分）比较。
3. **简单基线**：与网络邻近度、共同邻居、标签传播、逻辑回归等方法比较；在小数据或只有拓扑信息时，简单方法常常同样好（代码示例中，GCN 在空手道网络上并不比标签传播更准）。
4. **方差与可复现**：报告多个随机种子、多次划分的均值与离散程度；超参数在验证集而不是测试集上选择。
5. **输入图的质量**：GNN 把输入图当作“真实”结构，但生物网络本身是有噪声、有缺失、有偏倚的测量结果（见[测量误差、缺失与偏倚](network-construction.bias-and-missingness.html)）。
6. **外部验证**：预测性能好不等于生物学上正确；关键预测应有独立数据集或实验的验证。
:::

## 网络科学中的可解释性与因果 {#interpretability-causality}

### 两种“解释”

讨论网络模型的可解释性时，要区分两个问题：

- **模型解释**：模型为什么做出这个预测？例如 GNN 的预测依赖于哪些节点、边和特征。
- **机制解释**：生物系统为什么表现出这个现象？例如哪些分子相互作用导致了疾病表型。

前者是后者的必要条件而非充分条件：即使准确找出了模型依赖的子图，那也只是模型学到的统计规律，可能来自数据偏倚而不是生物机制。

### 事后解释与内在可解释

- **事后解释方法**：基于梯度的显著性图和类激活映射（DeepFRI 用它定位功能残基）；GNNExplainer（Ying 等，2019）为每个预测寻找一个对预测影响最大的紧凑子图和特征子集；注意力权重（GAT）也常被当作解释，但注意力大小与因果重要性并不等价。
- **内在可解释的模型**：模型结构本身对应科学概念，例如网络邻近度、扩散得分、元路径计数（Hetionet，见[异质网络、知识图谱与图机器学习](network-medicine.knowledge-graphs.html)）、稀疏线性模型。Rudin（2019）主张，在高风险决策中应优先使用内在可解释的模型，而不是先训练黑箱再去解释它。

::: {.callout-warn}
**事后解释的局限**：不同解释方法对同一预测常给出不同的重要子图；解释结果对随机种子和输入扰动敏感；解释的“合理性”往往由研究者根据已有知识判断，容易产生确认偏差。报告解释结果时，应检验其稳定性（多次训练、多种方法），并用独立证据（文献、实验）而不是“看起来合理”来评价。
:::

### 网络中的因果问题

本站各专题中出现的网络，大多数边表示的是**统计依赖**而不是因果作用：

| 网络 | 边的含义 | 能否直接回答“干预 $i$ 会怎样” |
|---|---|---|
| 功能连接（相关） | 两个信号的同步变化 | 不能，共同输入、间接通路都会产生相关 |
| 偏相关网络、高斯图模型 | 给定其他变量后的条件依赖 | 不能，无向且对未测混杂敏感（见[横断面统计依赖与因果作用](symptom-networks.dependence-vs-causation.html)） |
| 共表达网络 | 表达量协同变化 | 不能（见[网络推断问题](gene-network-inference.inference-problem.html)） |
| 物理相互作用网络（PPI） | 两分子可以结合 | 只说明可能性，不说明在某细胞状态下是否发生、方向如何 |
| 调控网络（有扰动数据支持） | 转录因子对靶基因的调控 | 部分可以，取决于扰动实验的覆盖 |

从观测数据推断因果网络需要额外假设：**有向无环图**（DAG）框架下的因果发现算法要求因果充分性（无未测混杂）和忠实性；**格兰杰因果**只表示时间上的可预测性；**有效连接**模型（如动态因果模型）需要预设候选结构。最直接的证据来自**干预**：基因敲除或 CRISPR 扰动（结合单细胞测序的大规模扰动筛选）、药物处理、脑刺激。

网络结构指标同样需要谨慎地解读为因果：中心性高的节点不一定是干预的最佳靶点——枢纽可能只是因为被研究得多（研究偏倚），或者只是许多通路的“下游汇合点”。[网络可控性与稳定性](controllability.html)提供了从动力学模型出发讨论“干预哪里”的框架，但它的结论依赖于动力学模型和网络结构的正确性。

::: {.callout-def}
**因果表示学习**：Schölkopf 等（2021）讨论了把因果推断与表示学习结合的方向——从高维观测中学习具有因果意义的变量，使模型在分布变化和干预下仍然有效。对生物医学网络而言，这意味着把扰动数据、时间信息和先验网络结合起来，而不是只在观测关联上训练预测模型。这一方向仍处于早期。
:::

::: {.callout-bio}
**从预测到机制的证据链**：一项可信的网络预测研究通常包括（1）网络或模型预测候选靶点、药物或基因；（2）与度基线、随机基线和已有方法比较；（3）在独立数据集（另一队列、另一数据库版本、时间上更晚的记录）中验证；（4）关键预测用干预实验（敲除、药物处理）检验。Stokes 等（2020）的抗生素发现和 Gysi 等（2021）的 COVID-19 药物重定位研究（见[药物重定位：从网络预测到外部验证](network-medicine.drug-repurposing.html)）都包含了实验验证环节。
:::

### 前沿方向一览

### 高阶网络

普通网络只表示两两关系，而许多生物过程涉及三个以上元素同时作用：蛋白复合物、多个脑区的协同激活、多个基因共同调控。**高阶网络**用超图（hypergraph）或单纯复形（simplicial complex）表示这种群体相互作用。Battiston 等（2020）的综述系统总结了高阶相互作用的表示方法和动力学后果，例如高阶耦合可以让同步或传播出现突变式转变。详见[高阶相互作用：超图与单纯复形](reporting-frontiers.higher-order.html)。

### 图神经网络

**图神经网络（GNN）**通过在邻居之间反复“传递消息”学习节点和图的表示，可用于节点分类、链接预测和图分类。图卷积网络（Kipf 与 Welling，2017）是常见的入门模型。生物医学中，GNN 被用于预测药物–靶点相互作用、药物组合副作用（如 Decagon，Zitnik 等，2018）、分子性质，以及基于脑网络的疾病分类。需要注意：GNN 的性能高度依赖输入图的质量和数据划分方式，[疾病模块、网络邻近度与药物重定位](network-medicine.html)中讨论的数据泄漏与研究偏倚问题同样存在；可解释性也仍是挑战。详见[图神经网络](reporting-frontiers.graph-neural-networks.html)。

### 多组学与多层网络

单一组学只看到系统的一个切面。**多层网络（multilayer network）**把基因组、转录组、蛋白组、代谢组以及临床表型放在不同层中，用层间边连接对应的实体（Kivelä 等，2014 给出了多层网络的统一数学框架）。[动态功能连接与多层脑网络](dynamic-brain-networks.html)中的结构–功能多层脑网络、[网络医学](network-medicine.html)中的异质知识图谱，都是这一方向的例子。单细胞多组学使“细胞类型特异的调控网络”成为可能，也让[基因调控网络推断](gene-network-inference.html)中的推断可靠性问题变得更突出：Pratapa 等（2020）的基准比较显示，单细胞数据上的调控网络推断算法整体准确度有限。详见[多层与相互依赖网络](reporting-frontiers.multilayer-networks.html)。

### 跨方向的共同问题

1. **表示的选择**：同一个系统可以表示为两两网络、超图、时间网络或多层网络。Torres 等（2021）提出，表示的选择应由研究问题和数据决定，并讨论了不同表示之间信息的得失。“用更复杂的表示”本身不是贡献，要说明它回答了简单表示回答不了的问题。
2. **零模型的推广**：每种新表示都需要相应的随机化基线——随机超图、打乱时间戳、层内重连与层间置换、保持度的随机图上的嵌入性能。
3. **基准与评估**：机器学习方法需要公开的、划分合理的基准数据集，以及统一的报告标准。
4. **从关联到干预**：网络方法最终要服务于干预（选择药物、靶点、刺激部位），这需要因果层面的证据。

::: {.callout-warn}
新方法不会自动解决老问题。无论是高阶网络还是图神经网络，节点和边怎样定义、与什么比较、结论对分析选择是否稳健，这些问题都依然存在。本站各专题反复强调的零模型与敏感性分析，在前沿方法中同样适用。
:::

## 数学推导与算法 {#derivations}

### 一、贝蒂数的秩公式

$k$ 维链群 $C_k$ 是以 $k$-单纯形为基的向量空间（维数 $n_k$），边界算子 $\partial_k:C_k\to C_{k-1}$ 的矩阵即 $B_k$。由 $\partial_{k}\partial_{k+1}=0$，有 $\mathrm{im}\,\partial_{k+1}\subseteq\ker\partial_k$，同调群 $H_k=\ker\partial_k/\mathrm{im}\,\partial_{k+1}$，其维数

$$
\beta_k=\dim\ker B_k-\operatorname{rank}B_{k+1}=(n_k-\operatorname{rank}B_k)-\operatorname{rank}B_{k+1}.
$$

**霍奇分解**：$C_k=\mathrm{im}\,B_{k+1}\oplus\mathrm{im}\,B_k^{\top}\oplus\ker L_k$，三部分两两正交。由于 $L_k=B_k^{\top}B_k+B_{k+1}B_{k+1}^{\top}$ 是两个半正定矩阵之和，$L_kx=0$ 当且仅当 $B_kx=0$ 且 $B_{k+1}^{\top}x=0$，因此 $\dim\ker L_k=\beta_k$。对 $k=1$，$\ker L_1$ 中的向量是边上的“调和流”：既无源汇（$B_1x=0$，散度为零），也不能写成三角形的边界（$B_2^{\top}x=0$，旋度为零），它们恰好绕着“洞”流动。

**计算复杂度**：基于矩阵秩的方法在单纯形数目 $n$ 上为 $O(n^3)$；持续同调的标准算法是对按过滤顺序排列的边界矩阵做列约简，最坏情况同为立方复杂度，实践中通常接近线性。团复形中三角形数目可达 $O(N^3)$，这是 TDA 只适用于中小规模网络或需要稀疏化的原因。

### 二、超拉普拉斯矩阵的两个极限

多重网络上节点–层 $(i,\alpha)$ 的状态 $x_{i\alpha}$ 满足

$$
\dot{x}_{i\alpha}=\sum_j A^{[\alpha]}_{ij}(x_{j\alpha}-x_{i\alpha})+D_x\sum_{\beta\ne\alpha}(x_{i\beta}-x_{i\alpha}),
$$

即 $\dot{x}=-\mathcal{L}x$，$\mathcal{L}=\bigoplus_\alpha L^{[\alpha]}+D_x\,(L_{\text{layer}}\otimes I_N)$，两层时 $L_{\text{layer}}=\begin{pmatrix}1&-1\\-1&1\end{pmatrix}$。

- **小 $D_x$**：取 $x=(\mathbf{1}_N,-\mathbf{1}_N)$。由于 $L^{[\alpha]}\mathbf 1=0$，直接计算得 $\mathcal{L}x=(2D_x\mathbf 1_N,-2D_x\mathbf 1_N)=2D_x\,x$，所以 $2D_x$ **总是** $\mathcal{L}$ 的一个特征值，且该特征向量与 $\mathbf 1_{2N}$ 正交，故 $\lambda_2\le2D_x$。用瑞利商同样可得：层内项为 0，层间项为 $D_x\sum_i(1-(-1))^2=4ND_x$，除以 $x^{\top}x=2N$ 得 $2D_x$。当 $D_x$ 足够小时 $\lambda_2=2D_x$（Gómez 等，2013）。
- **大 $D_x$**：层间耦合迫使 $x_{i1}\approx x_{i2}$，令 $x_{i1}=x_{i2}=y_i$，限制在这个子空间上的瑞利商为 $\frac{y^{\top}(L^{[1]}+L^{[2]})y}{2y^{\top}y}$，因此 $\lambda_2\to\lambda_2\big((L^{[1]}+L^{[2]})/2\big)$。由于 $\lambda_2$ 是凹函数（瑞利商最小值），$\lambda_2\big(\tfrac{L^{[1]}+L^{[2]}}{2}\big)\ge\tfrac12\big(\lambda_2(L^{[1]})+\lambda_2(L^{[2]})\big)$，可以超过任一单层。

### 三、时间一致可达性的扫描算法

把接触按时间排序，维护布尔矩阵 $R$（$R_{ij}=1$ 表示从 $i$ 出发的信息已能到达 $j$），初始 $R=I$。每遇到一次无向接触 $(u,v,t)$：

$$
R_{\cdot u}\leftarrow R_{\cdot u}\lor R_{\cdot v},\qquad R_{\cdot v}\leftarrow R_{\cdot u}\lor R_{\cdot v}.
$$

扫描结束时 $R$ 即为可达矩阵。复杂度 $O(N\cdot M)$（$M$ 为接触数）。同一时刻的多次接触需要约定处理顺序（或限制每个时间步只传一步），这一约定会影响结果，应在方法中写明。

### 四、拉普拉斯特征映射

目标 $\sum_{ij}W_{ij}\|y_i-y_j\|^2=2\,\mathrm{tr}(Y^{\top}LY)$。在约束 $Y^{\top}DY=I$ 下引入拉格朗日乘子，驻点条件为 $LY=DY\Lambda$，即广义特征值问题 $Ly=\lambda Dy$。令 $u=D^{1/2}y$，等价于对称归一化拉普拉斯 $\mathcal{L}_{\text{sym}}=D^{-1/2}LD^{-1/2}$ 的普通特征值问题 $\mathcal{L}_{\text{sym}}u=\lambda u$。最小特征值 0 对应常向量 $y=\mathbf 1$（平凡解），取接下来的 $d$ 个特征向量作为 $d$ 维嵌入。代码示例使用 $\mathcal{L}_{\text{sym}}$ 的特征向量 $u$；如需严格对应上式，可再左乘 $D^{-1/2}$。

### 五、从谱图卷积到 GCN

谱图卷积把信号 $x$ 变换到拉普拉斯 $\mathcal{L}_{\text{sym}}=U\Lambda U^{\top}$ 的特征基上滤波：$g_\theta\star x=Ug_\theta(\Lambda)U^{\top}x$。为避免特征分解，用切比雪夫多项式近似 $g_\theta$；Kipf 与 Welling（2017）取一阶近似并设 $\lambda_{\max}\approx2$：

$$
g_\theta\star x\approx\theta_0x+\theta_1(\mathcal{L}_{\text{sym}}-I)x=\theta_0x-\theta_1D^{-1/2}AD^{-1/2}x .
$$

再令 $\theta=\theta_0=-\theta_1$ 减少参数，得到 $\theta(I+D^{-1/2}AD^{-1/2})x$。矩阵 $I+D^{-1/2}AD^{-1/2}$ 的特征值在 $[0,2]$ 内，多层堆叠时可能导致数值不稳定，于是采用**重归一化技巧**，以 $\tilde{A}=A+I$、$\tilde{D}_{ii}=\sum_j\tilde{A}_{ij}$ 代替，得到 $\hat{A}=\tilde{D}^{-1/2}\tilde{A}\tilde{D}^{-1/2}$，其特征值在 $(-1,1]$ 内。多通道输入与输出时即 $H^{(l+1)}=\sigma(\hat{A}H^{(l)}W^{(l)})$。

**过平滑的谱解释**：$\hat{A}$ 是对称矩阵，最大特征值为 1，对应特征向量 $u_1\propto\tilde{D}^{1/2}\mathbf 1$；若图连通且非二部，其余特征值 $|\mu_i|<1$。于是 $\hat{A}^kX=u_1u_1^{\top}X+\sum_{i\ge2}\mu_i^k u_iu_i^{\top}X$，第二项按 $|\mu_2|^k$ 衰减。代码示例中 $|\mu_2|\approx0.76$，32 层后剩余部分约为 $0.756^{32}\approx1.3\times10^{-4}$，与数值结果（$2\times10^{-4}$）量级一致。

### 六、GCN 训练的梯度（两层、交叉熵）

记 $Z_1=\hat{A}XW_1$，$H_1=\mathrm{ReLU}(Z_1)$，$Z_2=\hat{A}H_1W_2$，$P=\mathrm{softmax}(Z_2)$，损失只在已标注节点集合 $\mathcal{Y}_L$ 上计算：$\mathcal{J}=-\frac{1}{|\mathcal{Y}_L|}\sum_{v\in\mathcal{Y}_L}\log P_{v,y_v}$。则

$$
\frac{\partial\mathcal{J}}{\partial Z_2}=\frac{M(P-Y)}{|\mathcal{Y}_L|},\quad \frac{\partial\mathcal{J}}{\partial W_2}=(\hat{A}H_1)^{\top}\frac{\partial\mathcal{J}}{\partial Z_2},\quad \frac{\partial\mathcal{J}}{\partial W_1}=(\hat{A}X)^{\top}\Big[\Big(\hat{A}^{\top}\frac{\partial\mathcal{J}}{\partial Z_2}W_2^{\top}\Big)\odot\mathbf{1}(Z_1>0)\Big],
$$

其中 $M$ 是只保留已标注行的对角掩码矩阵。注意未标注节点虽然不贡献损失，却通过 $\hat{A}$ 参与前向传播——这正是“半监督”的含义，也是图上的数据泄漏容易发生的地方：测试节点的特征在训练时已被邻居“看到”。

## 生物医学应用 {#biomedical}

复杂网络分析在生物医学工程中的意义，在于它提供了一种**介于还原与整体之间的描述层次**：既不把系统看成孤立元件的总和，也不停留在“一切都相互关联”的泛泛之谈，而是把“关联的模式”本身作为测量对象。

这种视角已经进入多个应用方向：脑网络指标被用来刻画个体差异和疾病状态；症状网络帮助思考精神障碍的维持机制和干预靶点；网络医学为药物重定位提供可计算的优先排序；基因调控网络推断帮助解析细胞状态的转录程序。与此同时，各领域也都经历了“从兴奋到审慎”的过程：小世界与无标度的普遍性被重新检验，症状中心性的稳定性受到质疑，单细胞 GRN 推断在真实数据上表现有限。成熟的网络研究者，既要会用这些工具，也要知道它们在哪里会失效。

前沿方向在生物医学中的对应关系可以概括如下：

| 生物医学问题 | 数据形态 | 合适的表示 | 本专题页面 |
|---|---|---|---|
| 蛋白复合物、代谢反应、共病模式 | 集合（多个实体同时出现） | 超图、单纯复形 | [高阶相互作用](reporting-frontiers.higher-order.html) |

## 适用范围与常见误用 {#limitations}

1. **误区**：报告越长、图越多越好。→ **正解**：每张图回答一个问题；冗余图表会稀释主要结论。
2. **误区**：口头报告时把所有分析步骤按时间顺序讲一遍。→ **正解**：按研究问题组织，先讲结论，方法只讲理解结果所必需的部分。
3. **误区**：局限部分写得越少越好，以免削弱结论。→ **正解**：主动、具体地讨论局限及你做过的检验，正是分析深度的体现。
4. **误区**：审阅他人的研究就是挑错，或者应尽量委婉、只说优点。→ **正解**：要复述其贡献，区分主要与次要问题，给出有依据的批评和可行建议；对事不对人。
5. **误区**：前沿方法（如 GNN）一定优于经典网络指标。→ **正解**：要与简单基线（如度、邻近度、逻辑回归）比较，并检查数据泄漏；简单方法在小数据上常常更稳健。
6. **误区**：网络图上看到了团块，说明存在模块。→ **正解**：力导向布局的团块依赖算法和随机初值；模块要用模块度、零模型和稳定性分析来确认，图只用于展示。
7. **误区**：把团复形或共现数据当作“高阶相互作用”的证据。→ **正解**：团复形完全由两两边决定；共现不等于不可分解的群体作用，需要检验高阶项是否超出两两模型的预期。
8. **误区**：时间数据先聚合成静态网络再分析，结论不变。→ **正解**：聚合会高估可达性、忽略阵发性和接触顺序；应与打乱时间戳等零模型比较，确认时间结构是否重要。
9. **误区**：多层网络的层间耦合参数可以随意设定。→ **正解**：$\omega$、$D_x$ 等参数通常没有实测依据，结论应在参数范围内检查稳健性，并与单层和聚合分析比较。
10. **误区**：嵌入或 GNN 找到的“重要子图”就是生物机制。→ **正解**：模型解释只反映模型学到的统计规律，机制结论需要独立数据和干预实验的支持。
11. **误区**：中心性高的节点就是最好的干预靶点。→ **正解**：统计依赖网络中的中心性不是因果效应，枢纽地位也可能来自研究偏倚；干预问题需要因果证据或动力学模型。

## 核心文献 {#references}

### Bassett & Sporns 2017：Network neuroscience

- **背景**：网络科学进入神经科学后，需要一个统一的视角来整合从分子到行为的多尺度网络。*Nature Neuroscience* 20:353–364，DOI [10.1038/nn.4502](https://doi.org/10.1038/nn.4502)。
- **核心内容**：综述网络神经科学的核心概念（模块、枢纽、动态、控制）及其跨尺度应用，讨论多层网络和网络控制等方向。
- **阅读提示**：读的时候对照[贯穿网络科学的五条主线](reporting-frontiers.cross-cutting-themes.html)，标出文中对应的段落；这篇文章几乎覆盖了网络结构指标、网络模型、社团结构、传播、同步、可控性与脑网络等专题的概念。
- **思考题**：文中提到的哪一个方向与你的研究最接近？若把你的研究推进一步，会用到哪个专题的方法？

### Battiston 等 2020：Networks beyond pairwise interactions: structure and dynamics

- **背景**：两两相互作用的网络框架能否描述群体相互作用？*Physics Reports* 874:1–92，DOI [10.1016/j.physrep.2020.05.004](https://doi.org/10.1016/j.physrep.2020.05.004)。
- **核心内容**：系统介绍超图、单纯复形等高阶表示，高阶网络上的随机游走、传播、同步等动力学，以及在脑、生态、社会系统中的应用。
- **阅读提示**：篇幅很长，建议只读引言和与[网络上的传播与免疫](spreading.html)、[同步与协同动力学](synchronization.html)相关的传播、同步章节；数学细节可以跳过。对照[高阶相互作用：超图与单纯复形](reporting-frontiers.higher-order.html)中的定义与算例。
- **思考题**：在你的研究对象中，有哪些“三个以上元素同时作用”的现象被两两网络遗漏了？

### Holme & Saramäki 2012：Temporal networks

- **背景**：接触、通信与神经活动都发生在特定时刻，静态网络无法表示时间顺序。*Physics Reports* 519(3):97–125，DOI [10.1016/j.physrep.2012.03.001](https://doi.org/10.1016/j.physrep.2012.03.001)。
- **核心内容**：时间网络的表示（接触序列、区间图）、时间一致路径与可达性、时间网络上的中心性与基序、随机化参照模型，以及传播等动力学过程。
- **阅读提示**：重点读时间一致路径和随机化参照模型两部分，对照[时间网络](reporting-frontiers.temporal-networks.html)中的算例与代码。
- **思考题**：你的数据如果有时间戳，聚合成静态网络时丢失了什么？用哪种随机化可以检验这些信息是否重要？

### Kivelä 等 2014：Multilayer networks

- **背景**：多重网络、时间网络、相互依赖网络等概念在不同文献中名称和定义各异。*Journal of Complex Networks* 2(3):203–271，DOI [10.1093/comnet/cnu016](https://doi.org/10.1093/comnet/cnu016)。
- **核心内容**：提出以节点–层二元组为基础的统一框架与术语，整理了多层网络的结构指标、动力学与各类特例之间的对应关系，是多组学网络的理论基础。
- **阅读提示**：先读一般定义与特例分类部分，再对照[多层与相互依赖网络](reporting-frontiers.multilayer-networks.html)与[多层网络](dynamic-brain-networks.multilayer.html)。
- **思考题**：你的多组学或多模态数据中，哪些层共享同一组节点（多重网络），哪些层是不同类型的实体（需要层间依赖边）？

### Grover & Leskovec 2016：node2vec: Scalable feature learning for networks

- **背景**：怎样从网络结构中自动学习节点特征，同时兼顾社团（同质性）与结构角色？*Proceedings of the 22nd ACM SIGKDD*，855–864，DOI [10.1145/2939672.2939754](https://doi.org/10.1145/2939672.2939754)。
- **核心内容**：用参数 $p$、$q$ 控制的二阶有偏随机游走生成节点序列，再用 skip-gram 学习嵌入，在节点分类与链接预测上与 DeepWalk 等方法比较。
- **阅读提示**：对照[网络表示学习](reporting-frontiers.network-embedding.html)中的转移概率算例；注意链接预测实验中测试边如何从网络中移除、负样本如何选取。
- **思考题**：在 PPI 网络上，你希望嵌入捕捉的是“同一复合物”（社团）还是“同为枢纽”（结构角色）？$q$ 应如何选择？

### Zitnik、Agrawal 与 Leskovec 2018：Modeling polypharmacy side effects with graph convolutional networks

- **背景**：多药联用的副作用难以通过临床试验穷尽。*Bioinformatics* 34(13):i457–i466，DOI [10.1093/bioinformatics/bty294](https://doi.org/10.1093/bioinformatics/bty294)。
- **核心内容**：构建蛋白–蛋白、药物–蛋白、药物–药物（按副作用类型区分）的多关系图，用图卷积网络预测药物组合的特定副作用。
- **阅读提示**：对照[疾病模块、网络邻近度与药物重定位](network-medicine.html)中的异质网络与网络药理学；注意作者怎样划分训练和测试数据，思考是否存在泄漏风险。
- **思考题**：与网络邻近度方法相比，这类深度学习方法的优势和代价各是什么？

### Krzywinski 等 2012：Hive plots—rational approach to visualizing networks

- **背景**：力导向布局的“毛线团”图难以解读、难以比较。*Briefings in Bioinformatics* 13(5):627–644，DOI [10.1093/bib/bbr069](https://doi.org/10.1093/bib/bbr069)。
- **核心内容**：提出把节点按规则放到放射状轴上的布局方法，使网络图的形状由节点属性决定，可重复、可比较。
- **阅读提示**：对照[网络可视化：原则与常见错误](reporting-frontiers.network-visualization.html)，思考“规则布局”与“力导向布局”各自适合回答什么问题。
- **思考题**：如果要比较患者组与对照组的脑网络，你会用什么规则安排节点的位置？

## 开放问题 {#questions}

1. 用[五条主线](reporting-frontiers.cross-cutting-themes.html)中的任意两条，为你正在进行的一项网络研究画一张“知识来源图”：每一步分别用到了哪些专题的概念？哪一步还需要补充其他领域的方法？
2. 在高阶网络、图神经网络、多组学网络三个方向中，选一个与你的研究最相关的，设想一个具体的生物医学问题，并说明它为什么不能用普通的两两网络很好地回答。
3. 找一张你或他人论文中的网络图，按[网络可视化：原则与常见错误](reporting-frontiers.network-visualization.html)中的清单逐条检查：它支持的结论是什么？换成矩阵图或统计图是否更清楚？
4. 对一个带时间戳的生物医学数据集（如医院接触、电子病历中的诊断序列），聚合网络与时间网络的结论在什么条件下会不同？你会用哪种随机化来检验？
5. 设计一个药物–靶点链接预测的评估方案：训练/测试怎样划分才能模拟“为一个全新药物预测靶点”的真实场景？应该与哪些简单基线比较？
6. 统计依赖网络中的“枢纽”在什么条件下可以被解释为干预靶点？需要补充哪些数据或实验？
