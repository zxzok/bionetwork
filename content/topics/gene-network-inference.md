## 概述 {#overview}

[生物分子网络与拓扑特征](molecular-networks.html)中的网络是“现成”的：PPI 来自实验数据库，调控边来自 ChIP 或文献整理。可是对多数疾病、组织和细胞类型，现成网络既不完整，也不特异。研究者手里更常有的是一张表达矩阵——几十到几千个样本、上万个基因，单细胞数据中则是成千上万个细胞。本专题回答的问题是：**能不能从表达数据反推出基因之间的网络？推出来的网络可信到什么程度？怎样用它找模块和关键基因？**

网络推断（network inference）是系统生物学最早的“逆问题”之一。前向问题是：已知调控网络，预测表达如何变化；逆问题是：观测到表达，反推网络。逆问题通常是**欠定**的——很多不同的网络能产生几乎相同的数据——所以每种方法都要加入假设：稀疏性、线性或单调关系、无环、稳态、已知转录因子列表，等等。理解一种方法，关键是理解它加了什么假设、需要什么数据、它的“边”究竟表示什么。

本专题按以下顺序展开：先说明推断问题本身为什么难，并给出方法家族的全景；然后讲最常用的共表达网络方法 WGCNA、共表达模块的解读、模块保守性检验与差异共表达分析；接着依次介绍偏相关与收缩估计、互信息与树模型、贝叶斯网络、动力学模型与单细胞拟时序方法，以及如何把 TF–靶基因数据库、ChIP-seq 与 ATAC-seq 等先验知识整合进推断；最后讲推断结果的评估指标与金标准的局限。[症状网络与网络精神病学](symptom-networks.html)中的偏相关、[网络构建与统计验证](network-construction.html)中的收缩与阈值、[社团结构与社区发现](community-structure.html)中的层次聚类会在这里再次出现。推断网络中的边属于“统计共表达或推断的调控关系”，与实验验证的物理相互作用、数据库推断的功能关联含义不同（区分见[生物分子网络的类型与数据来源](molecular-networks.network-types.html)）。

## 网络推断问题：从“一起变化”到“谁调控谁” {#inference-problem}

### 问题的形式

设表达矩阵 $X \in \mathbb{R}^{n \times p}$，$n$ 个样本、$p$ 个基因。**网络推断（network inference，也称网络反演 reverse engineering）** 的目标是给出一个 $p \times p$ 的边权矩阵 $W$，$W_{ij}$ 表示“基因 $i$ 与 $j$ 之间存在关联或调控关系”的强度或置信度。多数方法输出的是**边的排序**，而不是一个确定的图；把排序变成网络还需要选阈值。不同方法对“边”的含义不同：

| 边的含义 | 典型方法 | 网络类型 |
|---|---|---|
| 两基因表达共同变化 | 皮尔逊/斯皮尔曼相关、WGCNA | 无向、加权 |
| 给定其他基因后仍相关（直接关联） | 偏相关、高斯图模型（见[偏相关、高斯图模型与收缩估计](gene-network-inference.partial-correlation-shrinkage.html)） | 无向 |
| 统计依赖（含非线性） | 互信息、ARACNe、CLR | 无向 |
| 转录因子能预测靶基因 | LASSO 回归、GENIE3、GRNBoost2 | 有向（TF → 靶） |
| 条件概率分解中的父节点 | 贝叶斯网络 | 有向无环 |
| 一个基因的变化率依赖另一基因的水平 | 常微分方程模型、时间序列回归 | 有向，可含反馈 |
| 转录因子结合靶基因调控区并共表达 | SCENIC、SCENIC+ | 有向，含基序或染色质证据 |

::: {.callout-def}
**共表达（co-expression）**：两个基因在多个样本中的表达水平共同升降。共表达是**关联**而不是**调控**：它可能来自直接调控、共同上游调控者、细胞类型比例差异，甚至批次效应。

**基因调控网络（gene regulatory network, GRN）**：节点为基因（或其产物），有向边 $g \to j$ 表示 $g$ 的产物（通常是转录因子）直接影响 $j$ 的转录。“直接”与“有向”是 GRN 区别于共表达网络的两个要求。
:::

### 为什么难

1. **维度**：$p$ 常为 $10^4$，候选边约 $p^2/2 \approx 5\times10^7$ 条，而样本数 $n$ 常只有几十。估计这么多参数，样本远远不够，必须依赖稀疏性等假设。
2. **间接效应**：若 A 调控 B、B 调控 C，则 A 与 C 也高度相关。相关网络会把这条间接边一并画出。
3. **混杂**：组织样本中细胞组成不同，会让同一细胞类型的标志基因彼此“共表达”，其实它们只是一起随细胞比例变化。
4. **方向不可识别**：仅凭观测（非干预）数据，$A\to B$ 与 $B\to A$ 往往产生相同的联合分布。贝叶斯网络理论把这一点形式化为“马尔可夫等价类”（见[贝叶斯网络与因果结构学习](gene-network-inference.bayesian-networks.html)）。
5. **转录后调控看不见**：表达谱测的是 mRNA，蛋白修饰、定位、降解等调控无法直接反映；转录因子的活性常常与其 mRNA 水平脱节。
6. **评估难**：真实调控网络从未被完整测定过，金标准本身不完整（见[推断结果的评估](gene-network-inference.evaluation.html)）。

### 数据类型决定能回答什么

| 数据 | 能提供的信息 | 典型局限 |
|---|---|---|
| 稳态横断面（多个个体或组织样本） | 关联、模块 | 方向不可识别；混杂多 |
| 扰动后稳态（敲除、过表达、药物） | 干预信息，可识别方向 | 扰动数量有限；补偿效应 |
| 时间序列 | 先后次序，可建动力学模型 | 采样稀疏；时间点少 |
| 单细胞（含拟时序） | 细胞数多，可按细胞状态排序 | 稀疏、技术噪声；拟时序本身是推断 |
| 多组学（ChIP-seq、ATAC-seq、基序） | 结合或可及性证据，提示直接性 | 结合不等于调控；细胞类型特异性 |

::: {.callout-warn}
推断网络中的边是**假设**，不是**事实**。论文中写“基因 A 调控基因 B”之前，需要扰动实验（敲除、过表达、CRISPR 筛选）或独立的结合证据（ChIP-seq、基序）。只有相关证据时，写“共表达”或“推断的调控关系”。
:::

## 方法家族全景：假设与数据要求 {#method-landscape}

网络推断方法有上百种，但大致可归入六个家族。DREAM5 评估（Marbach 等, 2012）按类似思路把参赛方法分为回归、互信息、相关、贝叶斯网络、其他与元方法几类，并发现同一家族的方法往往犯相似的错误。下表按“边的统计含义”归纳各家族的核心假设与数据要求。

| 家族 | 代表方法 | 核心假设 | 数据要求 | 方向 | 计算规模 |
|---|---|---|---|---|---|
| 相关 / 共表达 | 皮尔逊、斯皮尔曼、WGCNA | 关联近似单调；模块由共同因子驱动 | $n\gtrsim 20$ 的横断面样本 | 无 | 全基因组，$O(p^2 n)$ |
| 偏相关 / 高斯图模型 | 收缩偏相关（GeneNet）、图形 LASSO、邻域选择 | 多元正态；精度矩阵稀疏 | $n$ 可小于 $p$，但需正则化 | 无 | 数千基因 |
| 信息论 | 互信息、CLR、ARACNe、MRNET、PIDC | 依赖可由 MI 刻画；DPI 时假设无三元直接环 | 估计 MI 需要较多样本（数百） | 无 | 全基因组 |
| 回归 / 树模型 | LASSO、Inferelator、GENIE3、GRNBoost2 | 靶基因可由少数调控因子预测 | 需要候选调控因子列表 | 由先验给定 | 全基因组，可并行 |
| 贝叶斯网络 | 静态 BN、动态 BN、模块网络 | 有向无环（静态）；局部条件分布形式 | 观测数据只能确定等价类；干预或时间数据更好 | 有（部分可识别） | 数十到数百基因 |
| 动力学模型 | 线性 ODE、NIR、SCODE、SINCERITIES | 系统由微分方程驱动；稳态或时间导数可估计 | 扰动后稳态或时间序列/拟时序 | 有 | 数十到数百基因 |

各家族之间并非互斥：Inferelator 把回归写成 ODE 的离散形式；SCENIC 先用树模型找共表达靶基因，再用基序数据库过滤；PIDC 是信息论方法，但专为单细胞设计。

### 怎样选择

- **目标是降维和找与性状相关的基因程序**：用共表达网络（WGCNA）即可，不需要调控方向；重点放在模块的稳健性与混杂控制上（见[解读共表达模块](gene-network-inference.module-interpretation.html)与[模块保守性](gene-network-inference.module-preservation.html)）。
- **目标是区分直接与间接关联**：偏相关或 ARACNe/CLR；样本少于基因时必须收缩或正则化。
- **目标是找某细胞状态的关键转录因子**：回归/树模型加先验知识（SCENIC 一类），并用转录因子活性而非 mRNA 水平做下游分析。
- **目标是因果方向与动力学预测**：需要扰动或时间数据，配合贝叶斯网络或 ODE 模型；纯横断面观测数据无法单独完成。

::: {.callout-warn}
DREAM5 的一个结论是：没有哪个家族在所有数据上都最好，不同家族各有偏好的网络结构（例如对级联、前馈环的识别能力不同），把多种方法的排序取平均往往最稳健（见 [Marbach 2012](paper-marbach2012_wisdom.html)）。实际分析中，若关键结论只在一种方法下成立，应当视为不稳健。
:::

## WGCNA：加权基因共表达网络分析 {#wgcna}

WGCNA（weighted gene co-expression network analysis）由 Zhang 与 Horvath（2005）提出理论框架，Langfelder 与 Horvath（2008）发布 R 包。它的目标不是逐条确认调控边，而是把上万个基因**压缩成十几个模块**，再把模块与临床性状关联。

### 从相关到邻接：软阈值

先算基因两两相关系数 $r_{ij}$。**硬阈值**做法是 $|r_{ij}| > \tau$ 记一条边，问题在于结果对 $\tau$ 很敏感，阈值附近的微小差异会让边忽有忽无。WGCNA 改用**软阈值（soft thresholding）**：

无符号网络：

$$a_{ij} = |r_{ij}|^{\beta}$$

有符号网络：

$$a_{ij} = \left(\frac{1+r_{ij}}{2}\right)^{\beta}$$

幂次 $\beta$ 越大，弱相关被压得越小，强相关保留得越多。例如 $\beta = 6$ 时，$r = 0.9$ 得 $0.53$，$r = 0.5$ 只剩 $0.016$。有符号网络把负相关基因视为不相连，更符合“同一模块基因同向变化”的直觉，近年使用更多。

### 怎么选 $\beta$：无标度拟合准则

WGCNA 假设生物网络近似无标度（见[小世界与无标度网络模型](network-models.html)）。对每个候选 $\beta$，计算每个基因的连接度 $k_i = \sum_{j \ne i} a_{ij}$，把 $k$ 分箱，拟合 $\log_{10} p(k)$ 对 $\log_{10} k$ 的直线，记拟合优度 $R^2$。**选使 $R^2$ 首次达到约 0.8–0.9（且斜率为负）的最小 $\beta$**，同时检查平均连接度不要降得太低。

::: {.callout-def}
**无标度拟合指数（scale-free topology fit index）**：$\log p(k)$ 与 $\log k$ 线性回归的 $R^2$，通常乘以斜率的负号，使斜率为正的情况得到负值。它是选 $\beta$ 的经验准则，不是对网络无标度性的检验。
:::

::: {.callout-warn}
样本有很强的分组结构（如肿瘤 vs 正常、两个批次）时，大量基因随分组同向变化，$R^2$ 可能在任何 $\beta$ 下都达不到 0.8。这时应先检查批次与离群样本，而不是一味加大 $\beta$。WGCNA 的 FAQ 也建议样本数不少于 15–20，否则相关估计噪声太大。
:::

### 拓扑重叠：用“共同邻居”去噪

单个相关系数噪声大。WGCNA 引入**拓扑重叠矩阵（topological overlap matrix, TOM）**：

$$\mathrm{TOM}_{ij} = \frac{l_{ij} + a_{ij}}{\min(k_i, k_j) + 1 - a_{ij}},\qquad l_{ij} = \sum_{u \ne i,j} a_{iu}a_{uj}$$

两个基因不仅自身相关，而且与同一批基因相关，TOM 才高。这与[网络结构指标与随机图](network-metrics.html)中的“共同邻居”、[社团结构与社区发现](community-structure.html)中社团的“内部连接稠密”是同一个思想。

### 模块、特征基因与性状关联

1. **聚类**：以 $1-\mathrm{TOM}$ 为距离做平均连锁层次聚类（见[社团结构与社区发现](community-structure.html)），得到基因树。
2. **切树**：用动态剪切（dynamic tree cut）把树切成模块，规定最小模块大小（常用 20–30）；未归入任何模块的基因记为灰色。
3. **模块特征基因（module eigengene, ME）**：对模块内基因的标准化表达做主成分分析，取第一主成分作为该模块在每个样本上的“代表表达”。
4. **模块–性状关联**：计算 ME 与临床性状（如疾病状态、分期、生化指标）的相关和 $p$ 值，筛出与性状最相关的模块。
5. **hub 基因**：用模块内连接度 $k_\mathrm{in}$ 或**模块成员度** $k_\mathrm{ME}(i) = \mathrm{cor}(x_i, \mathrm{ME})$ 排序，取排名靠前的基因；再结合基因显著性 $\mathrm{GS}_i = |\mathrm{cor}(x_i, y)|$（$y$ 为临床性状）筛选。
6. **功能注释**：对模块做 GO/KEGG 富集分析，给模块起“生物学名字”。

三个步骤的完整模拟示例（选 $\beta$、TOM 聚类、ME 与 hub）见[代码示例](gene-network-inference.html#code)的前三个单元。

::: {.callout-bio}
**例子**：在肿瘤表达谱中，WGCNA 常得到一个富集细胞周期与有丝分裂基因的模块，其特征基因与肿瘤分级、增殖指数正相关，模块 hub 往往是 *TOP2A*、*MKI67* 一类增殖标志物。这个结果在生物学上合理，但要注意：它主要反映了“样本中增殖细胞的比例”，未必揭示新的调控机制。
:::

## 解读共表达模块时要追问的三件事 {#module-interpretation}

**第一，模块由什么驱动？** 组织样本里，免疫浸润、基质比例、红细胞污染都能形成“漂亮”的模块。可以对照细胞类型标志基因列表，或用去卷积方法估计细胞比例后再看模块是否仍存在。Oldham 等（2008）在人脑转录组中发现，许多共表达模块恰好对应神经元、少突胶质细胞、星形胶质细胞和小胶质细胞等细胞类型——这既说明共表达能揭示组织的细胞组成，也提醒我们“模块 = 调控程序”的解读需要先排除细胞组成。

**第二，模块稳定吗？** 换一批样本、换 $\beta$、换最小模块大小，模块是否大体不变？WGCNA 提供模块保留性（module preservation）统计量，用于检验一个模块在独立数据集中是否重现，详见[模块保守性与可重复性检验](gene-network-inference.module-preservation.html)。

**第三，hub 是“驱动者”吗？** 共表达 hub 是与模块整体相关最强的基因，常常是该模块最好的**标志物**，但不一定是**上游调控者**。转录因子表达量往往较低、变化幅度小，反而不容易成为共表达 hub。代码示例的第三个单元演示了这一点：模拟中模块所有基因都只是同一潜在因子的读数，hub 只是噪声最小的读数。

## 模块保守性与可重复性检验 {#module-preservation}

### 问题：模块在另一组数据中还在吗？

在一组数据中找到的模块可能只是该样本的偶然结构。**模块保守性（module preservation，也译模块保留）** 问的是：参考数据集中定义的模块，在独立的检验数据集（另一批病人、另一组织、另一物种）中是否仍然表现为一个紧密连接的基因集合。这与“在检验数据中重新聚类，看能否得到对应模块”不同：后者依赖检验数据的聚类参数，两组模块的交叉表可能因为切树高度不同而看起来不一致，即使网络结构其实保留了。Langfelder 等（2011, *PLoS Computational Biology*）为此提出了一组**不需要在检验数据中重新识别模块**的网络统计量。

### 两类统计量

对参考数据中的模块 $q$（基因集合 $\mathcal M_q$，大小 $m$），在检验数据中计算：

- **密度类（density）**：模块基因在检验数据中是否仍彼此高度相关。例如模块内平均相关（按参考网络中的符号对齐）$\text{meanCor}$、平均邻接 $\text{meanAdj}$、第一主成分解释的方差比例 $\text{propVarExpl}$、平均模块成员度 $\text{meanKME}$。
- **连接模式类（connectivity）**：模块内部“谁与谁连得更紧”的模式是否保留。例如参考与检验数据中模块内相关矩阵上三角的相关 $\text{cor.cor}$、模块内连接度 $k_{\mathrm{IM}}$ 的跨数据相关 $\text{cor.kIM}$、$k_{\mathrm{ME}}$ 的跨数据相关 $\text{cor.kME}$。

密度高说明“这批基因仍在一起”；连接模式保留说明“模块内部的枢纽与结构也一样”。一个模块可以密度保留而连接模式改变（例如枢纽基因在疾病中换了），也可以反过来。

### 置换零分布与 Zsummary

每个观测统计量本身的大小难以判断，需要零分布：随机置换检验数据中的模块标签（等价于随机抽取同样大小的基因集合），重复计算统计量，得到均值与标准差，把观测值换算成 $Z$ 分数。WGCNA 的汇总方式是：

$$
Z_{\text{density}}=\operatorname{median}\{Z_{\text{meanCor}},Z_{\text{meanAdj}},Z_{\text{propVarExpl}},Z_{\text{meanKME}}\},\qquad
Z_{\text{connectivity}}=\operatorname{median}\{Z_{\text{cor.kIM}},Z_{\text{cor.kME}},Z_{\text{cor.cor}}\},
$$

$$
Z_{\text{summary}}=\tfrac12\left(Z_{\text{density}}+Z_{\text{connectivity}}\right).
$$

Langfelder 等根据模拟给出经验阈值：$Z_{\text{summary}}>10$ 为保守性的强证据，$2<Z_{\text{summary}}<10$ 为弱到中等证据，$Z_{\text{summary}}<2$ 为无证据；作者强调这些只是粗略的指导值。

::: {.callout-warn}
**Zsummary 随模块大小增大**：同样程度的保守性，大模块的 $Z$ 值更大（就像大样本的检验统计量更大）。比较不同大小的模块时，作者建议看观测统计量本身，或用基于观测统计量排序的 **medianRank**（排名越小保守性越强），它对模块大小的依赖小得多。
:::

### 算例与生物学例子

代码示例的“模块保守性检验”单元在参考数据中定义两个模块，检验数据中模块 1 保留、模块 2 的基因彼此独立。简化版计算得到模块 1 的 $Z_{\text{summary}}\approx 24$（其中 $Z_{\text{density}}\approx 43$，$Z_{\text{connectivity}}\approx 4$），模块 2 约为 0.3。模块 1 的连接模式 $Z$ 远小于密度 $Z$，因为在本模拟中模块基因的载荷差异不大，内部“枢纽结构”本身就弱。

::: {.callout-bio}
**例子**：Langfelder 等（2011）把雌性小鼠肝脏中的胆固醇生物合成模块拿到其他性别与组织的网络中检验：在雄性肝脏中有强保守性证据，在雌性脑和肌肉中则没有证据，在脂肪组织中弱保留。这类结果帮助区分“组织共享的调控程序”与“组织特异的程序”。该文还给出一个应用：按交叉表看，雄性的几个模块在雌性数据中“没有对应模块”，但网络保守性统计量显示它们其实有中等到强的保守性，从而避免了错误地声称存在性别差异。
:::

### 实践要点

1. 两个数据集应使用同一套基因（取交集）与相近的预处理；
2. 参考与检验数据的样本应相互独立，不能把同一批样本切两半后宣称“外部验证”；
3. 保守性高说明模块是可重复的统计结构，不等于它是调控程序（细胞组成同样会在两个数据集中稳定重现）；
4. 用 bootstrap 或子抽样检查模块在同一数据集内的稳定性，与跨数据集保守性互补（一般原则见[稳定性与可重复性](network-construction.stability-reproducibility.html)）。

## 差异共表达分析 {#differential-coexpression}

### 差异表达与差异共表达

**差异表达（differential expression, DE）** 比较一个基因在两种条件下的平均水平；**差异共表达（differential co-expression, DC）** 比较两个基因之间的**相关**在两种条件下是否不同。二者回答不同的问题：一个转录因子在疾病中失活，可能不改变自身 mRNA 水平，却会让它与靶基因的协同变化消失。反过来，一组基因可以整体上调但彼此的相关结构不变。

::: {.callout-def}
**差异共表达**：基因对 $(i,j)$ 在条件 A 与 B 中的相关系数不同，$\rho_{ij}^{A}\ne\rho_{ij}^{B}$。可在三个层次上分析：**基因对**（哪些相关改变了）、**基因**（差异连接度：一个基因与其他基因的总连接是否改变）、**模块**（一组基因的协同是否整体增强或丧失，常称“重布线” rewiring）。
:::

### 基因对水平：Fisher $z$ 检验

两组独立样本（大小 $n_A,n_B$）的相关差异，用 Fisher $z$ 变换（推导见[Fisher z 变换与样本量](network-construction.derivations.html)）：

$$
Z_{ij}=\frac{\operatorname{artanh} r^{A}_{ij}-\operatorname{artanh} r^{B}_{ij}}{\sqrt{\dfrac{1}{n_A-3}+\dfrac{1}{n_B-3}}}\;\overset{H_0}{\sim}\;\mathcal N(0,1).
$$

**算例**：$n_A=n_B=50$，$r^A=0.6$，$r^B=0.2$。$\operatorname{artanh}0.6=0.693$，$\operatorname{artanh}0.2=0.203$，差为 0.490；分母 $\sqrt{2/47}=0.206$；$Z=2.38$，双侧 $p\approx0.017$。如果这是 $p=10^4$ 个基因中的一对，需要对约 $5\times10^7$ 次检验做多重校正（如 BH-FDR），这一对远远达不到显著。这说明**基因对水平的差异共表达检验功效很低**，相关差异要非常大、样本要很多才能检出。

### 基因与模块水平

为了提高功效，常把信号聚合起来：

- **差异连接度**：$\Delta k_i=k_i^{A}/\max_u k_u^{A}-k_i^{B}/\max_u k_u^{B}$，比较一个基因在两个网络中的（标准化）连接度；
- **模块水平检验**：比较一个基因集合内的平均相关或平均邻接，用**样本标签置换**得到零分布（打乱 A/B 标签，保持基因间结构）；
- **专门算法**：DiffCoEx（Tesson 等, 2010, *BMC Bioinformatics*）在 WGCNA 框架上以两条件邻接矩阵之差构造相异度，对其做层次聚类，直接找“协同性改变”的模块；DICER（Amar 等, 2013, *PLoS Computational Biology*）寻找在疾病中相关性改变的基因模块及模块对，用于分析疾病中被改变的调控网络。

代码示例的“差异共表达”单元演示了两种信号的分离：基因 0–9 在条件 A 中共表达、在 B 中失去协同（BH-FDR<0.05 的 54 个差异共表达基因对中有 38 个落在这 10 个基因内部），而基因 10–19 是整体上调的差异表达基因，$t$ 检验找到的正是它们。

::: {.callout-warn}
**相关差异不一定是“重布线”**：（1）**方差改变**：一组中某基因的表达范围变窄（如疾病中被抑制到接近检测下限），相关自然下降，这是“范围限制”效应，不代表调控关系消失；（2）**细胞组成**：疾病组织中某细胞类型比例改变，会让该细胞类型的标志基因在一组中“共表达”、另一组中不共表达；（3）**样本量不同**：两组样本量悬殊时，小组的相关更不稳定，检验需按上式用各自的 $n$；（4）**均值与相关的耦合**：计数数据的相关受平均表达水平影响，应先做方差稳定化。差异共表达结果应与差异表达、细胞比例估计一起报告。
:::

## 偏相关、高斯图模型与收缩估计 {#partial-correlation-shrinkage}

### 偏相关去除的是什么

偏相关在控制其他变量后度量两变量的关联。在多元正态假设下，偏相关为 0 等价于条件独立，非零偏相关构成**高斯图模型（GGM）**的边。偏相关与精度矩阵的关系、它在链式结构与对撞结构中的表现，已在[连接强度的估计](network-construction.edge-estimation.html)和[偏相关与高斯图模型](symptom-networks.gaussian-graphical-model.html)中讲过，这里只强调基因表达数据的特点：$p\gg n$。

**三基因算例**。只控制一个变量时，一阶偏相关有闭式公式：

$$
r_{13\cdot2}=\frac{r_{13}-r_{12}r_{23}}{\sqrt{(1-r_{12}^2)(1-r_{23}^2)}}.
$$

设 1→2→3 为调控链，$r_{12}=0.8$，$r_{23}=0.7$。若 1 与 3 之间没有直接作用，期望 $r_{13}=0.8\times0.7=0.56$——相关网络会画出 1–3 这条边；但 $r_{13\cdot2}=(0.56-0.56)/\cdots=0$，偏相关正确地去掉了它。若观测到 $r_{13}=0.7$，则 $r_{13\cdot2}=0.14/\sqrt{0.36\times0.51}\approx0.33$，提示 1 与 3 之间在 2 之外还有联系。

### $p>n$ 时的问题

全偏相关需要协方差矩阵的逆。样本协方差 $S$ 的秩至多为 $n-1$，当 $p\ge n$ 时不可逆；即使 $n$ 略大于 $p$，$S$ 的小特征值被严重低估，求逆后噪声被放大。常见对策有两类：**收缩**（把 $S$ 拉向一个简单目标，保证可逆且条件数好）与**稀疏正则化**（图形 LASSO、邻域选择，见[正则化估计：EBICglasso](symptom-networks.regularization.html)）。基因网络中，Schäfer 与 Strimmer（2005）的收缩方法因为有**解析的最优收缩强度**、计算快，而被广泛使用（R 包 GeneNet、corpcor）。

### Schäfer–Strimmer 收缩估计

对标准化数据（即相关矩阵 $R$），以单位阵为目标：

$$
R^{*}=\lambda I+(1-\lambda)R,\qquad\text{即 } r^{*}_{ij}=(1-\lambda)r_{ij}\ (i\neq j).
$$

使均方误差最小的收缩强度为

$$
\lambda^{*}=\frac{\sum_{i\neq j}\widehat{\operatorname{Var}}(r_{ij})}{\sum_{i\neq j}r_{ij}^{2}},
$$

其中 $\widehat{\operatorname{Var}}(r_{ij})=\dfrac{n}{(n-1)^3}\sum_{k=1}^{n}(w_{kij}-\bar w_{ij})^2$，$w_{kij}=z_{ki}z_{kj}$ 是第 $k$ 个样本中两基因标准化值的乘积。直观地说：**相关系数整体越“不可靠”（分子大）、相关整体越弱（分母小），就收缩得越多**。$\lambda^*$ 截断到 $[0,1]$。得到 $R^*$ 后求逆，按 $\rho_{ij}=-\omega_{ij}/\sqrt{\omega_{ii}\omega_{jj}}$ 换算偏相关。推导见[数学推导与算法](gene-network-inference.derivations.html)。

收缩只给出非稀疏的偏相关估计，还需要判断哪些边显著。Schäfer 与 Strimmer（2005, *Bioinformatics*）提出用经验贝叶斯混合模型拟合全部偏相关的分布（大部分来自“零边”的零分布，少部分来自真边），对每条边给出**局部错误发现率**（local fdr），以此选边。

### 模拟中的表现

代码示例的“收缩估计偏相关”单元在一个含 8 个枢纽的稀疏 GGM（80 个基因）上比较 $|r|$ 与收缩偏相关：

| $n$ | $\lambda^*$ | AUPR（$|r|$） | AUPR（收缩偏相关） |
|---|---|---|---|
| 40 | 0.79 | 0.53 | 0.43 |
| 100 | 0.69 | 0.81 | 0.79 |
| 400 | 0.34 | 0.90 | 0.95 |
| 1600 | 0.10 | 0.88 | 1.00 |

（随机预测的 AUPR 为 0.02。）结果说明两点：其一，同一枢纽的两个邻居之间没有直接边却有明显相关（$n=400$ 时平均 $|r|\approx0.21$），偏相关把它们压到约 0.04，这是偏相关的价值；其二，**样本很少时偏相关并不总是优于相关排序**——估计一个精度矩阵比估计相关矩阵需要更多信息，收缩又把信号压得很弱。$n$ 增大后偏相关继续接近真值，相关排序则停在间接边造成的上限附近。

::: {.callout-warn}
（1）偏相关依赖“所有相关变量都在模型中”：漏掉的共同调控因子仍会制造虚假偏相关；（2）对撞结构 $A\to C\leftarrow B$ 中，控制 $C$ 会让本不相关的 $A$、$B$ 出现偏相关；（3）GGM 假设线性关系与近似正态，计数数据需先变换；（4）收缩估计偏向单位阵，边权系统性偏小，只宜用于排序与显著性判断，不宜与未收缩的估计直接比较大小。
:::

## 超越相关：信息论、树模型与单细胞方法 {#beyond-correlation}

### 互信息与 ARACNe

**互信息（mutual information, MI）** 衡量两个变量的统计依赖，非线性关系（如 U 形）也能捕捉：

$$I(X;Y) = \sum_{x,y} p(x,y)\log\frac{p(x,y)}{p(x)p(y)}$$

对二元高斯变量，$I = -\tfrac12\log(1-\rho^2)$，与相关系数单调对应。实践中需要离散化或核密度估计，样本少时估计偏差明显。

**ARACNe**（Margolin 等，2006）在 MI 网络上加一步**数据处理不等式（data processing inequality, DPI）**：若 A→B→C 构成马尔可夫链，则 $I(A;C) \le \min\{I(A;B), I(B;C)\}$。于是对每个三角形，删掉其中 MI 最小的边（允许一个容差），以去除间接关联。DPI 的代价是：真实存在的三元前馈环（见[网络基序：自调控与前馈环](molecular-networks.network-motifs.html)）也可能被误删。

### CLR：用背景分布校正 MI

有些基因（如高表达、高变异的基因）与所有基因的 MI 都偏高。**CLR**（context likelihood of relatedness，Faith 等, 2007）把每个 MI 值放到两个基因各自的“背景”中比较：

$$
z_i=\max\!\left(0,\frac{I_{ij}-\mu_i}{\sigma_i}\right),\qquad
z_j=\max\!\left(0,\frac{I_{ij}-\mu_j}{\sigma_j}\right),\qquad
\mathrm{CLR}_{ij}=\sqrt{z_i^2+z_j^2},
$$

$\mu_i,\sigma_i$ 是基因 $i$ 与所有其他基因 MI 的均值与标准差。只有当一条边对**至少一个端点**而言是“突出的”，它才得到高分。Faith 等把 CLR 用于大肠杆菌表达数据汇编，并用 ChIP 实验检验了部分新预测的调控关系。MRNET（Meyer 等, 2007）是另一种思路：对每个基因按“最大相关、最小冗余”逐个选择邻居，避免把彼此冗余的间接邻居都选进来。

代码示例中，在含线性、饱和与 U 形调控的 30 基因模拟网络上（400 个样本），$|r|$、MI、CLR、ARACNe 的 AUPR 分别为 0.62、0.83、0.90、0.88（随机 0.09）；U 形调控边的平均 $|r|$ 仅 0.08，而 MI 为 0.30，远高于所有候选对的平均 MI（0.12）。这说明 MI 能找回相关看不见的非单调依赖，CLR 与 DPI 则进一步削弱了间接边。

### 回归：把推断拆成 $p$ 个变量选择问题

回归方法对每个靶基因 $j$ 单独建模：用候选调控因子集合 $\mathcal R$（通常是已知转录因子）的表达预测 $x_j$，非零（或重要）的系数就是入边。最简单的是 LASSO：

$$
\hat\beta^{(j)}=\arg\min_{\beta}\ \frac1{2n}\Big\|x_j-\sum_{g\in\mathcal R\setminus\{j\}}\beta_g x_g\Big\|^2+\lambda\sum_g w_g|\beta_g|.
$$

把 $\lambda$ 从大到小扫一遍（正则化路径），系数越早进入模型，边越可信，这可以直接作为边的得分。权重 $w_g$ 是整合先验知识的接口：对数据库支持的边减小惩罚（见[先验知识整合](gene-network-inference.prior-knowledge.html)）。Inferelator（Bonneau 等, 2006）把这一回归框架与动力学模型结合，同时处理稳态与时间序列数据。在 GGM 中对每个基因做 LASSO 回归再合并邻居（邻域选择，Meinshausen & Bühlmann, 2006）与这里的思路相同，只是不区分调控因子与靶基因。

### GENIE3：把推断变成树模型回归

GENIE3（Huynh-Thu 等，2010）把 $p$ 基因的网络推断拆成 $p$ 个回归问题：对每个靶基因 $j$，用所有候选转录因子的表达预测 $x_j$，回归器为随机森林或极端随机树；每个转录因子在树中的**特征重要性**作为边 TF→$j$ 的权重。最后把全部边按权重排序。

- 优点：能捕捉非线性与交互作用；天然给出**有向**边（前提是事先给定转录因子列表）；在 DREAM4 多因子模拟数据挑战中表现最好。
- 局限：计算量大（GRNBoost2 用带早停的梯度提升树加速，Moerman 等, 2019）；重要性只是排序分数，没有直接的统计显著性；仍然是关联，不是因果。

### 单细胞：SCENIC

单细胞 RNA 测序给出成千上万个细胞，样本数不再是瓶颈，但数据稀疏、技术噪声大。**SCENIC**（Aibar 等，2017）分三步：

1. 用 GENIE3/GRNBoost2 得到每个转录因子的共表达靶基因集合；
2. 用 RcisTarget 检查这些靶基因的启动子区是否富集该转录因子的结合基序，只保留有基序支持的靶基因，得到**调控子（regulon）**；
3. 用 AUCell 在每个细胞中给每个调控子打活性分数，再按调控子活性聚类细胞或比较细胞状态。

第 2 步把序列证据引入了推断，使边更接近“直接调控”。这是用生物学先验知识约束网络推断的一个范例。SCENIC+（Bravo González-Blas 等, 2023）进一步利用同一细胞的染色质可及性（scATAC-seq）把增强子纳入调控子。单细胞数据特有的问题与依赖拟时序的方法见[动力学模型、时间序列与单细胞拟时序](gene-network-inference.dynamic-models.html)。

### 时间与扰动数据

稳态表达谱很难区分方向。时间序列（或单细胞拟时序）可以利用“先变后变”的信息，例如用微分方程或格兰杰因果思路建模；扰动数据（敲除、药物处理、CRISPR 筛选）提供干预信息，是识别因果方向最有力的证据。概率框架下的因果方向问题见[贝叶斯网络与因果结构学习](gene-network-inference.bayesian-networks.html)，微分方程框架见[动力学模型、时间序列与单细胞拟时序](gene-network-inference.dynamic-models.html)。

## 贝叶斯网络与因果结构学习 {#bayesian-networks}

### 模型

**贝叶斯网络（Bayesian network, BN）** 用一个有向无环图（DAG）$G$ 表示联合分布的分解：

$$
P(x_1,\dots,x_p)=\prod_{i=1}^{p}P\big(x_i\mid x_{\mathrm{Pa}(i)}\big),
$$

$\mathrm{Pa}(i)$ 是节点 $i$ 在 $G$ 中的父节点。图中缺少的边对应条件独立：每个节点在给定父节点后，与其非后代节点条件独立。条件分布可以是离散的（把表达分为低/中/高）或线性高斯的。Friedman 等（2000, *Journal of Computational Biology*）最早系统地把 BN 用于酵母表达数据；Friedman（2004, *Science*）综述了概率图模型在细胞网络推断中的用法。

### 学习结构

结构学习通常是**打分加搜索**：给每个候选 DAG 打分（如 BIC 或贝叶斯 BDe 分数），在 DAG 空间中搜索高分结构。常用分数可以按节点分解，

$$
\mathrm{score}(G\mid D)=\sum_{i=1}^{p}\mathrm{score}\big(x_i,\mathrm{Pa}(i)\mid D\big),
$$

所以局部改动（加、删、反转一条边）只需重算一两个节点的分数，贪心爬山或 MCMC 才可行。但 DAG 的数目随 $p$ 超指数增长，精确求最优在一般情形下是 NP 困难的，实际只能处理几十到几百个基因，或先限定每个节点的候选父节点。

由于数据有限，最高分结构往往不唯一也不稳定。Friedman 等（2000）的做法是**不相信单个网络，而对“特征”求置信度**：对数据做 bootstrap，每次学习一个网络，统计某条边或某个“X 是 Y 的马尔可夫毯成员”在多少次中出现。模块网络（Segal 等, 2003, *Nature Genetics*）则把共表达基因归为模块，同一模块共享调控程序，以减少参数并提高可解释性。

### 马尔可夫等价与方向的可识别性

::: {.callout-def}
**马尔可夫等价类（Markov equivalence class）**：蕴含相同条件独立关系集合的 DAG 构成一个等价类。仅凭观测数据，算法最多只能识别到等价类，而不能区分类内的不同 DAG。两个 DAG 等价，当且仅当它们有相同的骨架（忽略方向后的无向图）和相同的 **v 结构**（$A\to C\leftarrow B$，且 $A$、$B$ 不相邻）。
:::

例如 $A\to B\to C$、$A\leftarrow B\leftarrow C$、$A\leftarrow B\to C$ 都只蕴含“$A\perp C\mid B$”，属于同一等价类，观测数据无法分辨；而 $A\to B\leftarrow C$ 蕴含“$A\perp C$ 但给定 $B$ 后不独立”，可以被识别。这就是为什么只用横断面表达数据时，大部分边的方向是不可识别的。

**干预打破等价**：如果实验固定了 $B$（敲除或抑制剂），$A\to B$ 时 $A$ 的分布不变，而 $B\to A$ 时 $A$ 的分布会随之改变。

::: {.callout-bio}
**例子**：Sachs 等（2005, *Science*）用流式细胞术在单个人类 T 细胞中同时测量多个磷酸化信号蛋白，并施加多种针对特定分子的刺激与抑制。由于有大量单细胞观测和干预条件，贝叶斯网络恢复了已知信号通路中的大部分关系，并对模型提出的新预测做了实验检验。这项工作常被引用为“干预 + 大样本”使因果结构学习可行的范例；它处理的是十余个信号分子，而不是全基因组。
:::

### 局限与扩展

1. **无环假设**：静态 BN 不能表示反馈环，而反馈在基因调控中非常普遍。**动态贝叶斯网络**（DBN）把时间展开：$x(t)$ 的父节点取自 $x(t-1)$，环在时间展开后变成无环。
2. **离散化损失信息**，而线性高斯 BN 又不能刻画非线性。
3. **隐变量**：未测量的共同调控因子会制造虚假的边，因果充分性假设（所有共同原因都被测量）在表达数据中几乎不成立。
4. **规模**：全基因组 BN 不可行，通常先用共表达或先验知识缩小候选集。

## 动力学模型、时间序列与单细胞拟时序 {#dynamic-models}

### 线性常微分方程模型

把基因表达看作随时间演化的动力系统，在某个工作点附近线性化：

$$
\frac{d\mathbf x}{dt}=A\mathbf x+B\mathbf u,
$$

$A_{ij}$ 表示基因 $j$ 的水平对基因 $i$ 变化率的影响（$A_{ij}\ne0$ 即有向边 $j\to i$），$\mathbf u$ 是外加扰动。这个模型允许反馈环，方向也有明确含义。与[网络可控性与稳定性](controllability.html)中的线性系统是同一个数学对象，只是在这里 $A$ 未知、需要从数据估计。

**稳态扰动数据**：系统在扰动 $\mathbf u_k$ 下达到新稳态 $\mathbf x_k$，有 $A\mathbf x_k=-B\mathbf u_k$。做 $K$ 次扰动、把稳态排成矩阵 $X$，若 $K\ge p$ 且 $X$ 满秩，可解出 $A=-BUX^{-1}$。现实中扰动次数远少于基因数，于是加入稀疏假设（每个基因只有少数调控因子），对每一行做稀疏回归。Gardner 等（2003, *Science*）的 NIR 方法就是这样从扰动实验中推断大肠杆菌调控子网络，并用推断的网络识别化合物作用的靶基因。Bansal 等（2007, *Molecular Systems Biology*）的教程比较了这类方法与 ARACNe、贝叶斯网络在不同数据类型上的表现。

**时间序列数据**：用差分近似导数，$\big(\mathbf x(t+\Delta)-\mathbf x(t)\big)/\Delta\approx A\mathbf x(t)$，又回到回归问题。格兰杰因果的思路类似：若加入 $x_j$ 的过去值能显著改进对 $x_i$ 未来值的预测，就记 $j\to i$。时间点少、采样间隔大于调控时间尺度、所有基因受同一外部驱动（如细胞周期、昼夜节律）都会产生虚假的“先后”。

### 单细胞数据的特点

单细胞 RNA-seq 带来三个变化：

1. **样本多**：每个细胞是一个观测，相关和 MI 的估计方差变小；
2. **稀疏与技术噪声**：大量零值来自捕获效率而非真实不表达，相关被系统性压低；Skinnider 等（2019, *Nature Methods*）比较了多种关联度量在单细胞数据中的表现，发现比例性（proportionality）一类针对组成型数据设计的度量表现较好，而常用的皮尔逊相关并不理想；把相似细胞合并为“元细胞”或按细胞类型做伪批量（pseudobulk）也是常见的折中；
3. **异质性**：混合多种细胞类型时，细胞类型间的表达差异会主导共表达，应在细胞类型内分别推断，或明确把“细胞状态”作为变量。

### 拟时序方法

在分化、发育等连续过程中，可以先用拟时序（pseudotime）算法把细胞沿轨迹排序，再把排序当作“时间”使用：

- **SCODE**（Matsumoto 等, 2017）：在拟时序上拟合线性 ODE，并借助降维使大规模求解可行；
- **SINCERITIES**（Papili Gao 等, 2018）：比较相邻时间点之间表达分布的变化，用正则化回归推断调控边，再用偏相关判断激活或抑制；
- **LEAP**（Specht & Li, 2017）：沿拟时序计算带时滞的相关，取最大滞后相关作为有向边得分；
- **PIDC**（Chan 等, 2017）：基于部分信息分解的多元信息度量，**不需要拟时序**。

::: {.callout-warn}
BEELINE（Pratapa 等, 2020）在 12 种单细胞 GRN 推断算法上的结论值得记住：不需要拟时序的方法（GENIE3、GRNBoost2、PIDC）总体上更准确，在精心构建的布尔模型与真实数据上表现最稳定；依赖拟时序的方法在简单合成网络上可能得分很高，但对拟时序质量敏感——把拟时序打乱后性能明显下降。拟时序本身是推断结果，把它当作真实时间使用会把排序误差传递给网络。
:::

## 先验知识整合：TF–靶基因数据库、ChIP-seq 与 ATAC {#prior-knowledge}

### 为什么需要先验

表达数据本身只含关联信息；在真核生物中，DREAM5 显示纯表达数据驱动的推断在酵母上表现很有限。而关于“谁可能调控谁”，生物学已经积累了大量独立证据。把这些证据作为**先验**，可以缩小搜索空间、为方向提供依据，并减少间接边。

### 先验的来源

| 来源 | 证据类型 | 代表资源 | 主要局限 |
|---|---|---|---|
| 文献整理 | 小规模实验验证的调控关系 | RegulonDB（大肠杆菌）、TRRUST v2（人和小鼠，Han 等, 2018） | 偏向研究充分的转录因子；缺乏细胞类型信息 |
| 整合资源 | 多来源证据合并并分级 | DoRothEA（Garcia-Alonso 等, 2019，按证据强度分 A–E 级）、CollecTRI（Müller-Dott 等, 2023） | 不同证据的可比性；版本更新 |
| ChIP-seq | 转录因子在全基因组的结合位点 | ENCODE、ChIP-Atlas | 结合不等于调控；依赖抗体与细胞系 |
| 基序 | 调控区中的转录因子结合基序 | cisTarget 数据库、JASPAR 等基序库 | 同家族转录因子基序相似；假阳性多 |
| 染色质可及性 | ATAC-seq / scATAC-seq 显示的开放区域，与基序结合可推断候选结合 | SCENIC+、CellOracle 的基础 GRN | 开放不等于结合；增强子–基因配对不确定 |

### 整合策略

1. **限定候选集**：只允许转录因子作为调控因子（GENIE3、GRNBoost2 的做法）；或只保留有基序/ChIP 支持的边（SCENIC 的剪枝步骤）。简单可靠，但先验中缺失的真边永远找不到。
2. **作为软约束**：在回归中对先验边减小惩罚（Inferelator 一类方法；Greenfield 等, 2013, *Bioinformatics* 研究了如何在先验有错时稳健地加入先验），或在贝叶斯网络中给结构加先验概率。数据仍可推翻先验。
3. **估计转录因子活性**：转录因子的 mRNA 水平常不反映其活性。把先验靶基因集合当作“读数”，用靶基因的表达估计转录因子活性（DoRothEA、CollecTRI 的主要用途），再用活性而非 mRNA 做下游分析或网络推断。
4. **事后注释**：先用数据推断网络，再检查高分边在先验中的富集，作为合理性检验。

代码示例的“回归与先验整合”单元模拟了一个“一半真边、一半假边”的先验：样本少（$n=30$）时，先验把 LASSO 路径的 AUPR 从 0.55 提高到 0.64；样本多（$n=120$）时，仅数据 AUPR 为 0.80，加入先验反而降到 0.70；两种情形下先验中错误边的得分都被抬高。先验的价值取决于数据强弱与先验质量。

::: {.callout-warn}
**循环论证**：如果先验来自某数据库，评估时就不能再用同一数据库（或与之高度重叠的资源）作金标准，否则性能被系统性高估。BEELINE 使用的真实数据金标准正包括 ChIP-seq 与 DoRothEA、TRRUST 等非细胞类型特异的调控网络，比较方法时要留意每种方法是否已经“见过”这些边。此外，数据库偏向研究充分的基因，依赖先验的方法会继承这种偏倚（见[数据库研究偏倚](network-construction.bias-and-missingness.html)）。
:::

## 推断结果的评估 {#evaluation}

::: {.callout-def}
**金标准（gold standard）**：用于评估推断网络的“已知真边”集合，常见来源有模拟网络（已知全部真边）、整理过的调控数据库（如大肠杆菌的 RegulonDB）、ChIP-seq 结合位点、扰动实验。所有真实金标准都不完整，未列入金标准的预测边不一定是假阳性。
:::

### 指标

推断方法通常输出一个**边的排序**。评估时按排名逐步纳入边，画 ROC 曲线和精确率–召回率（PR）曲线：

- **AUROC**：随机抽一条真边和一条非真边，真边排得更靠前的概率；随机预测为 0.5。
- **AUPR**：PR 曲线下面积，近似为“每找到一条真边时的精确率”的平均；随机预测约等于真边比例 $\pi$。
- **早期精度（early precision）**：前 $k$ 条预测中真边的比例，$k$ 取金标准中的真边数；**早期精度比**（EPR）是它与随机预测（$=\pi$）之比。BEELINE 同时报告 AUPR 比值与 EPR。实验验证的预算通常只够检验排名最前的几十条边，所以早期精度往往最贴近实际用途。

由于真边在全部候选边中极其稀少（常低于 1%），**AUPR 比 AUROC 更有区分度**（Saito & Rehmsmeier, 2015）。代码示例的“评估指标”单元构造了两个打分器：A 只把少数真边排在最前，B 把全部真边整体前移但前列被 30 个强假阳性占据。B 的 AUROC 更高（0.87 vs 0.70），但 A 的 AUPR（0.43 vs 0.14）和早期精度（0.40 vs 0）高得多。

**手算算例**：10 个候选对中有 3 条真边（$\pi=0.3$），按得分排序后的真假为 真、假、真、假、假、真、假、假、假、假。三条真边处的精确率分别为 $1/1$、$2/3$、$3/6$，AUPR $=(1+0.667+0.5)/3=0.72$，是随机的 2.4 倍；前 $k=3$ 条中有 2 条真边，早期精度 0.67，EPR $=2.2$；AUROC 为“真边排在假边前”的比例：第 1 名真边胜过 7 条假边，第 3 名胜过 6 条，第 6 名胜过 4 条，AUROC $=17/21=0.81$。

### 两项标志性评估

- **DREAM5**（Marbach 等，2012）：三十余种方法在模拟数据、大肠杆菌和酿酒酵母表达数据上同台比较（另有金葡菌数据，因缺乏可靠金标准未纳入评分），每份预测的 AUPR 与 AUROC 先与随机预测比较换算为 $p$ 值，再汇总成总分。没有一种方法在所有数据上都最好；把多种方法的排序整合起来（“群体智慧”）的结果最稳健；在酵母这类真核生物数据上，所有方法的表现都很有限。
- **BEELINE**（Pratapa 等，2020）：系统评估 12 种单细胞 GRN 推断算法。数据包括 6 种合成网络（线性、长线性、环、二分叉、二分叉汇合、三分叉）、4 个精心构建的布尔模型（皮层区域发育、腹侧脊髓发育、造血干细胞分化、性腺性别决定），以及 5 套真实单细胞数据；真实数据的金标准分三类：细胞类型特异 ChIP-seq、非细胞类型特异的调控数据库、STRING 功能相互作用。主要结论：方法在合成网络上比在布尔模型上表现好；在真实数据上，即使最好的方法表现也一般，多数方法的 EPR 接近随机；不需要拟时序的方法总体更准确。

### 金标准的局限

1. **不完整**：漏标的真边被算作假阳性，精确率被系统性低估。代码示例中，把金标准删去一半真边后，同一打分器前 20 条的表观精确率从 0.40 降到 0.20，AUPR 从 0.43 降到 0.28。
2. **不特异**：数据库中的调控关系多来自其他细胞类型或条件，在当前组织中未必活跃。
3. **证据类型不同**：ChIP-seq 测结合，敲除实验测功能后果（含间接效应），共表达测关联。评估一种方法时，金标准的证据类型决定了“真边”的含义。
4. **偏倚**：研究充分的转录因子拥有更多已知靶基因，偏好高表达、高连接基因的方法会因此占便宜。
5. **模拟的局限**：模拟网络的真边完整，但模拟器的动力学假设（如 GeneNetWeaver、BoolODE）可能偏向某些方法；模拟上的排名不能直接外推到真实数据。

::: {.callout-warn}
推断网络最不可靠的部分恰恰是“单条边”。更稳健的用法是**集体层面**的结论：模块、通路富集、调控子活性、与已知网络的整体重叠。把推断网络当作产生假设的工具，再用实验去检验。报告时应给出：候选边全集的定义、真边比例 $\pi$、AUPR 与 AUPR/$\pi$、早期精度，以及金标准的来源与覆盖范围。
:::

## 数学推导与算法 {#derivations}

本节补全 WGCNA 中软阈值、TOM 和模块特征基因的数学细节，推导数据处理不等式、收缩强度和差异共表达检验，给出 GENIE3 与模块保守性检验的伪代码，并写出用 AUPR 评估推断网络的具体计算。符号：$n$ 个样本、$p$ 个基因，$x_i\in\mathbb R^n$ 为基因 $i$ 的表达向量，$r_{ij}$ 为相关系数，$a_{ij}\in[0,1]$ 为邻接权重，$k_i=\sum_{u\ne i}a_{iu}$ 为连接度。

### 软阈值与 TOM 的性质

**软阈值保持排序、拉开差距**。$a_{ij}=|r_{ij}|^\beta$ 是 $|r|$ 的单调增函数，所以不改变边的强弱排序；但两条边的比值被放大为 $(|r_1|/|r_2|)^\beta$。例如 $r=0.9$ 与 $r=0.5$ 的比值从 1.8 变成 $1.8^6\approx34$。这就是“软”阈值：没有一刀切，但弱边的贡献被压到可以忽略。

**TOM 为什么在 $[0,1]$ 内**。由于 $a_{uj}\le1$，

$$
l_{ij}=\sum_{u\ne i,j}a_{iu}a_{uj}\le\sum_{u\ne i,j}a_{iu}=k_i-a_{ij},
$$

同理 $l_{ij}\le k_j-a_{ij}$，所以 $l_{ij}+a_{ij}\le\min(k_i,k_j)$；而分母 $\min(k_i,k_j)+1-a_{ij}\ge\min(k_i,k_j)$。故 $0\le\mathrm{TOM}_{ij}\le1$。$\mathrm{TOM}_{ij}=1$ 要求 $a_{ij}=1$ 且度较小的那个基因的所有邻居都是另一个基因的满权邻居；$\mathrm{TOM}_{ij}=0$ 要求二者既不相连也无共同邻居。在无权图上，TOM 就是“直接相连 + 共同邻居数”除以可能的最大值。

**模块特征基因**。把模块 $q$ 的 $m$ 个基因的表达逐基因标准化，得 $X^{(q)}\in\mathbb R^{n\times m}$，做奇异值分解 $X^{(q)}=UDV^\top$。特征基因取第一左奇异向量 $\mathrm{ME}_q=u_1$（即第一主成分得分的方向），其解释的方差比例为 $d_1^2/\sum_k d_k^2$。奇异向量的符号不唯一，WGCNA 把 ME 的符号调整为与模块平均表达正相关。模块成员度 $k_{\mathrm{ME}}(i)=\operatorname{cor}(x_i,\mathrm{ME}_q)$ 本质上是基因 $i$ 在第一主成分上的（标准化）载荷。

::: {.callout-warn}
若 $d_1^2/\sum d_k^2$ 很低（如低于 0.3），说明模块内部并不“一维”，用一个 ME 概括整个模块会丢失大量信息，ME–性状关联也就难以解释。
:::

### 收缩强度的推导

设要估计的量为 $\sigma_{ij}$（这里是真实相关 $\rho_{ij}$），无偏估计为 $s_{ij}$（$E s_{ij}=\sigma_{ij}$），目标 $t_{ij}$ 为常数（相关矩阵向单位阵收缩时，非对角 $t_{ij}=0$）。收缩估计 $s^*_{ij}=\lambda t_{ij}+(1-\lambda)s_{ij}$ 的总均方误差为

$$
\mathcal L(\lambda)=\sum_{i\neq j}E\big(s^*_{ij}-\sigma_{ij}\big)^2=\sum_{i\neq j}\Big[(1-\lambda)^2\operatorname{Var}(s_{ij})+\lambda^2(t_{ij}-\sigma_{ij})^2\Big].
$$

对 $\lambda$ 求导令其为 0：$-(1-\lambda)\sum\operatorname{Var}(s_{ij})+\lambda\sum(t_{ij}-\sigma_{ij})^2=0$，得

$$
\lambda^*=\frac{\sum_{i\neq j}\operatorname{Var}(s_{ij})}{\sum_{i\neq j}\big[\operatorname{Var}(s_{ij})+(t_{ij}-\sigma_{ij})^2\big]}=\frac{\sum_{i\neq j}\operatorname{Var}(s_{ij})}{\sum_{i\neq j}E(t_{ij}-s_{ij})^2}.
$$

最后一步用了 $E(t-s)^2=\operatorname{Var}(s)+(t-\sigma)^2$。把未知的期望换成样本估计：分母用 $\sum r_{ij}^2$，分子用样本乘积 $w_{kij}$ 的经验方差，就得到正文中的 Schäfer–Strimmer 公式（Ledoit & Wolf, 2004 给出了以单位阵倍数为目标的同类结果）。公式表明：估计越不确定、或真值离目标越近，就越应该收缩。

### 数据处理不等式（DPI）

互信息的链式法则把 $I(A;B,C)$ 按两种顺序展开：

$$
I(A;B,C)=I(A;C)+I(A;B\mid C)=I(A;B)+I(A;C\mid B).
$$

若 $A\to B\to C$ 构成马尔可夫链，则给定 $B$ 后 $A$ 与 $C$ 独立，$I(A;C\mid B)=0$。于是 $I(A;C)=I(A;B)-I(A;B\mid C)\le I(A;B)$；同理 $I(A;C)\le I(B;C)$。ARACNe 据此对每个三角形删去 MI 最小的边。

```text
算法 1  ARACNe（简化版）
输入：表达矩阵 X（n×p）；MI 显著性阈值 α；DPI 容差 ε（0 表示严格 DPI，常用 0–0.15）
输出：无向网络
1. 对每对基因估计 I(i;j)（核密度或自适应分箱）              // O(p²·n)
2. 用置换得到零分布，删去 I(i;j) 不显著的边
3. 对每个三角形 (i,j,k)，若 I(i,j) < (1−ε)·min{I(i,k), I(j,k)}：标记 (i,j) 待删
4. 一次性删除所有标记边（先标记后删除，结果不依赖遍历顺序）
复杂度：第 3 步最坏 O(p³)；实际只需遍历第 2 步后剩余边构成的三角形
```

### GENIE3

GENIE3 的边权是随机森林（或极端随机树）的**方差减少重要性**。在树的一个内部节点 $\mathcal N$，样本集 $S$ 被特征 $g$ 划分为 $S_l$ 与 $S_r$，该节点的贡献为

$$
\Delta(\mathcal N)=|S|\operatorname{Var}(S)-|S_l|\operatorname{Var}(S_l)-|S_r|\operatorname{Var}(S_r),
$$

把特征 $g$ 在所有树、所有节点上的 $\Delta$ 求和并取平均，即为 $g$ 对该靶基因的重要性。

```text
算法 2  GENIE3
输入：表达矩阵 X（n×p，每个基因标准化为单位方差）；候选调控因子集合 R；
      树的数目 T（如 1000）；每次分裂考察的候选特征数 K（随机森林常取 sqrt(|R|)）
输出：按权重排序的有向边列表 (g → j, w_gj)
1. 对每个靶基因 j = 1..p：
2.     输入特征 ← R \ {j}；输出 ← x_j
3.     训练 T 棵树（随机森林：每棵树用 bootstrap 样本，每次分裂在随机选出的 K 个特征中
       找最优划分；极端随机树：用全部样本，分裂阈值也随机抽取）
4.     对每个 g ∈ R \ {j}：w_gj ← 所有树中以 g 分裂的节点的 Δ 之和 / T
5. 把全部 (g, j, w_gj) 汇总，按 w_gj 从大到小排序
复杂度：约 O(p · T · K · n log n)；对 p 个靶基因完全可并行
```

第 1 步中先把每个靶基因标准化为单位方差，是为了让不同靶基因的重要性可以放在一起排序。有向边的“方向”完全来自集合 $R$ 的先验设定。

### 差异共表达检验与模块保守性

**Fisher $z$ 检验的依据**：若 $(x_i,x_j)$ 近似二元正态，$\operatorname{artanh}r$ 近似服从 $\mathcal N\big(\operatorname{artanh}\rho,\,1/(n-3)\big)$。两组样本独立，所以差的方差为两组方差之和，标准化后在 $H_0:\rho^A=\rho^B$ 下近似标准正态。对 $p(p-1)/2$ 个基因对同时检验时，检验统计量之间高度相关（共享基因），BH 程序在正相关依赖下仍控制 FDR，但功效有限，因此常把检验聚合到基因或模块层面。

```text
算法 3  模块保守性的置换 Z 统计量（简化版）
输入：参考数据相关矩阵 R_ref；检验数据 X_test；模块 M（大小 m）；置换次数 B
1. 计算观测统计量：密度类 D = (meanCor, meanAdj, propVarExpl, meanKME)；
   连接模式类 C = (cor.kIM, cor.kME, cor.cor)，均在检验数据中、以参考数据为对照计算
2. 对 b = 1..B：在检验数据中随机抽取 m 个基因作为“伪模块”（置换模块标签），重算 D_b、C_b
3. 每个统计量的 Z = (观测值 − 置换均值) / 置换标准差
4. Zdensity = median(Z_D)；Zconnectivity = median(Z_C)；Zsummary = (Zdensity + Zconnectivity) / 2
复杂度：O(B · m² · n)；B 取 100–200 通常足以估计均值与标准差
```

### AUPR 的计算与基线

把推断结果排成边列表 $e_1,e_2,\dots$，金标准真边集合为 $G$，评估的候选边全集为 $\mathcal C$。前 $k$ 条预测中真阳性数为 $\mathrm{TP}_k$：

$$
P_k=\frac{\mathrm{TP}_k}{k},\qquad R_k=\frac{\mathrm{TP}_k}{|G|},\qquad \mathrm{AUPR}\approx\sum_k (R_k-R_{k-1})P_k .
$$

随机排序的期望精确率处处等于真边比例 $\pi=|G|/|\mathcal C|$，因此随机 AUPR $\approx\pi$。DREAM5 中 $\pi$ 常远低于 1%，所以“AUPR=0.05”可能已是随机水平的几倍，而 AUROC 在这种极端不平衡下会显得很高、区分度低。实践要点：$\mathcal C$ 只应包含金标准覆盖的调控因子与靶基因之间的边；PR 曲线不能在相邻点之间线性插值（Davis & Goadrich, 2006）；报告 AUPR 时应同时报告 $\pi$ 或 AUPR/$\pi$。

**不完整金标准的影响**：设真实真边集合为 $G^*$，金标准只覆盖其中比例 $c$（$G\subset G^*$，$|G|=c|G^*|$），且漏标与预测得分无关。则前 $k$ 条预测中被记为真阳性的期望数为 $c\cdot\mathrm{TP}^*_k$，表观精确率 $P_k\approx c\,P^*_k$，随机基线也同比变为 $c\,\pi^*$。所以**比值 AUPR/$\pi$ 对随机漏标近似不变，而 AUPR 本身被按比例低估**；若漏标与得分相关（例如数据库偏好研究充分的高表达基因，而方法也偏好它们），比值也会有偏。

## 研究前沿与开放问题 {#frontiers}

1. **共表达网络如何去混杂？** Parsana 等（2019, *Genome Biology*，DOI: [10.1186/s13059-019-1700-9](https://doi.org/10.1186/s13059-019-1700-9)）显示，技术因素和细胞组成会制造大量虚假共表达，用主成分校正可减少假边，但也可能去掉真实的全局信号。校正多少才“恰好”，尚无公认标准。
2. **扰动数据能否让推断真正因果？** 全基因组 Perturb-seq（Replogle 等, 2022, *Cell*，DOI: [10.1016/j.cell.2022.05.013](https://doi.org/10.1016/j.cell.2022.05.013)）提供了大规模敲低–表达响应。如何把这类数据与观测数据结合、在何种假设下可识别调控方向，是活跃的方法学问题。
3. **计算机模拟扰动是否可信？** CellOracle（Kamimoto 等, 2023, *Nature*，DOI: [10.1038/s41586-022-05688-9](https://doi.org/10.1038/s41586-022-05688-9)）用推断的 GRN 模拟转录因子扰动。这类预测在发育以外的疾病情境中准确率如何，系统性验证仍然缺乏。
4. **单细胞多组学推断**：同时测量转录组与染色质可及性的多组学数据使“增强子–基因–转录因子”三元调控可以被直接建模（SCENIC+，Bravo González-Blas 等, 2023）。Badia-i-Mompel 等（2023, *Nature Reviews Genetics*）的综述指出，这类方法的评估仍缺乏统一的金标准与基准，不同方法在同一数据上给出的网络重叠有限。
5. **网络如何连接 GWAS 与疾病机制？** “全基因模型”（Boyle, Li & Pritchard, 2017, *Cell*，DOI: [10.1016/j.cell.2017.05.038](https://doi.org/10.1016/j.cell.2017.05.038)）认为大量外周基因通过调控网络影响少数核心基因。能否用组织特异的调控网络定量检验这一假说，仍是开放问题。
6. **差异网络的统计推断**：在两种条件间比较整个网络（而不是逐边比较）时，如何在高维、小样本、细胞组成变化的情况下控制假阳性，仍缺少被广泛接受的标准做法。

## 生物医学应用 {#biomedical}

网络推断在疾病研究中的价值，主要体现在把高维表达数据变成可解释的单元。WGCNA 是生物医学文献中应用最多的网络方法之一：在阿尔茨海默病、自闭症、精神分裂症的脑组织表达谱中，研究者用共表达模块把成百上千个差异基因归纳为突触功能、小胶质细胞免疫、少突胶质细胞髓鞘等少数几条生物学“轴”，再与遗传风险位点作富集对照，判断哪些模块可能处于因果链上游。

::: {.callout-bio}
**自闭症脑组织的共表达模块**：Voineagu 等（2011, *Nature*）比较自闭症患者与对照的大脑皮层转录组，用共表达网络找到两个与疾病相关的模块：一个富集神经元与突触功能基因、在患者中下调，并富集自闭症遗传关联信号；另一个富集免疫与小胶质细胞相关基因、在患者中上调，但缺乏遗传关联富集。作者据此提出：前者更可能处于因果链上游，后者可能是继发反应。这个例子展示了“模块 + 遗传证据”判断方向的思路。
:::

::: {.callout-bio}
**从网络到可验证的主调控因子**：Basso 等（2005, *Nature Genetics*）把 ARACNe 用于人类 B 细胞表达谱，推断的 MYC 靶基因得到了实验支持。Carro 等（2010, *Nature*）在胶质瘤中用 ARACNe 重建转录网络，识别出 C/EBPβ 与 STAT3 是间充质表型的协同主调控因子，并在实验中证明二者共同沉默会削弱间充质特征与肿瘤侵袭性。这类研究的共同点是：网络只用来**排序候选**，结论来自后续的扰动实验。
:::

单细胞时代，SCENIC 一类方法让“细胞状态由哪些转录因子程序维持”变得可以系统地研究，例如在肿瘤微环境中区分不同 T 细胞耗竭状态的调控子。推断出的关键转录因子可以进一步作为扰动实验（CRISPR 敲除、过表达）的候选。差异共表达与模块保守性分析则常用于回答“疾病中哪些调控程序被重布线”“动物模型中的模块是否在人类组织中保留”这类问题。推断得到的模块与关键基因进一步进入[疾病模块与网络邻近度](network-medicine.html)分析时，应记住它们是统计推断的产物，而不是实验测得的相互作用。

需要警惕的是两类常见失误：其一，把 WGCNA hub 直接称作“关键调控因子”或“治疗靶点”，却没有任何方向性证据；其二，在小样本（如每组 5 例）数据上跑完整流程，模块和 hub 难以重复。[研究问题、可复现分析与敏感性分析](reproducible-research.html)中的敏感性分析正是为了应对这些问题。

## 适用范围与常见误用 {#limitations}

1. **误用**：相关系数高的基因对就是调控对。→ **正解**：相关可能来自共同上游、细胞比例、批次；调控需要方向性和直接性证据。
2. **误用**：WGCNA 选 $\beta$ 要让 $R^2$ 越接近 1 越好。→ **正解**：取首次达到约 0.8–0.9 的最小 $\beta$；$\beta$ 过大会让平均连接度过低，模块变得零碎。$R^2$ 只是经验准则，不证明网络无标度。
3. **误用**：模块 hub 基因就是驱动基因。→ **正解**：hub 是与模块特征基因最相关的基因，适合作标志物；驱动者需要扰动或遗传证据。
4. **误用**：GENIE3 输出了有向边，所以方向是被数据证明的。→ **正解**：方向来自“事先指定谁是转录因子”的先验，模型本身只做预测。
5. **误用**：推断方法在模拟数据上表现好，用到真实数据上也会好。→ **正解**：DREAM5 与 BEELINE 都显示，真实数据上的性能显著下降，且金标准本身不完整。
6. **误用**：在另一组数据中重新聚类没得到对应模块，就说模块不可重复。→ **正解**：重新聚类的结果受参数影响；应使用不依赖重新聚类的保守性统计量（Zsummary、medianRank），并注意 Zsummary 随模块大小增大。
7. **误用**：两组相关系数不同，就说调控关系在疾病中“重布线”。→ **正解**：先排除方差变化、细胞组成与样本量差异；基因对水平的检验功效很低，结论应聚合到模块层面并经置换检验。
8. **误用**：偏相关网络中有边，就说明两个基因直接相互作用。→ **正解**：偏相关只控制了纳入模型的变量；未测量的共同调控因子和对撞结构都会产生虚假偏相关。$p>n$ 时还需检查收缩强度与估计稳定性。
9. **误用**：贝叶斯网络学出的箭头就是因果方向。→ **正解**：仅用观测数据只能确定到马尔可夫等价类，多数箭头不可识别；需要干预或时间信息。
10. **误用**：用某数据库作先验，再用同一数据库作金标准评估。→ **正解**：这是循环论证；评估用的金标准应独立于推断时使用的先验。
11. **误用**：只报告 AUROC。→ **正解**：真边极稀少时 AUROC 区分度低，应报告 AUPR 及其相对随机的比值、早期精度，以及金标准的来源与覆盖范围。

### Langfelder & Horvath 2008：WGCNA: an R package for weighted correlation network analysis

- **背景**：Zhang 与 Horvath 2005 年提出软阈值与拓扑重叠的理论框架，此后需要一个标准化、可复用的软件实现。*BMC Bioinformatics* 9:559，DOI [10.1186/1471-2105-9-559](https://doi.org/10.1186/1471-2105-9-559)。
- **核心内容**：系统给出网络构建（软阈值、TOM）、模块检测（层次聚类与动态剪切）、模块特征基因、模块–性状关联、模块成员度与基因显著性、模块保留等函数及使用流程。
- **阅读提示**：重点看“网络构建”和“模块与性状关联”两部分的逻辑链；注意作者对样本量、离群样本和 $\beta$ 选择的建议。
- **思考题**：若数据只有 12 个样本且分为两组，WGCNA 哪些步骤最可能失效？应怎样改进研究设计？

### Langfelder 等 2011：Is my network module preserved and reproducible?

- **背景**：*PLoS Computational Biology* 7:e1001057，DOI [10.1371/journal.pcbi.1001057](https://doi.org/10.1371/journal.pcbi.1001057)。
- **核心内容**：提出不依赖在检验数据中重新聚类的密度与连接模式保守性统计量、置换 Z 分数与 Zsummary、medianRank，并用小鼠多组织、人与黑猩猩脑等数据演示。
- **思考题**：为什么交叉表（参考模块与检验模块的重叠）可能低估保守性？

### Margolin 等 2006：ARACNE

- **背景**：*BMC Bioinformatics* 7(Suppl 1):S7，DOI [10.1186/1471-2105-7-S1-S7](https://doi.org/10.1186/1471-2105-7-S1-S7)。
- **核心内容**：用互信息加数据处理不等式在哺乳动物细胞表达数据中重建调控网络；讨论了 DPI 在何种拓扑下能去除间接边、在何种拓扑下会误删真边。

### Faith 等 2007：CLR

- **背景**：*PLoS Biology* 5:e8，DOI [10.1371/journal.pbio.0050008](https://doi.org/10.1371/journal.pbio.0050008)。
- **核心内容**：在大肠杆菌表达数据汇编上提出 CLR，以 RegulonDB 为金标准比较多种方法，并用 ChIP 实验验证部分新预测。

### Huynh-Thu 等 2010：GENIE3

- **背景**：*PLoS ONE* 5:e12776，DOI [10.1371/journal.pone.0012776](https://doi.org/10.1371/journal.pone.0012776)。
- **核心内容**：把网络推断拆成每个靶基因的树模型回归，用特征重要性给边排序；在 DREAM4 多因子挑战中表现最好。

### Schäfer & Strimmer 2005：收缩估计与偏相关网络

- **背景**：*Statistical Applications in Genetics and Molecular Biology* 4:32，DOI [10.2202/1544-6115.1175](https://doi.org/10.2202/1544-6115.1175)；配套的经验贝叶斯选边方法见 *Bioinformatics* 21:754–764，DOI [10.1093/bioinformatics/bti062](https://doi.org/10.1093/bioinformatics/bti062)。
- **核心内容**：给出多种收缩目标下最优收缩强度的解析估计，使 $p\gg n$ 时的协方差与偏相关估计可行；用局部 fdr 判断偏相关网络中的显著边。
- **思考题**：收缩目标选单位阵意味着什么先验信念？当真实相关普遍较强时会怎样？

### Friedman 2004：Inferring cellular networks using probabilistic graphical models

- **背景**：*Science* 303:799–805，DOI [10.1126/science.1094068](https://doi.org/10.1126/science.1094068)。早期工作见 Friedman 等 2000, *Journal of Computational Biology*，DOI [10.1089/106652700750050961](https://doi.org/10.1089/106652700750050961)。
- **核心内容**：综述贝叶斯网络、动态贝叶斯网络与模块网络在基因表达和信号网络推断中的应用，讨论观测数据下方向的可识别性与干预数据的作用。

### Aibar 等 2017：SCENIC

- **背景**：*Nature Methods* 14:1083–1086，DOI [10.1038/nmeth.4463](https://doi.org/10.1038/nmeth.4463)。
- **核心内容**：共表达（GENIE3/GRNBoost2）+ 基序富集剪枝 + 细胞水平调控子活性（AUCell），把单细胞转录组分析从基因层面提升到调控程序层面。

### Marbach 等 2012：Wisdom of crowds for robust gene network inference

- **背景**：DREAM 社区组织公开挑战，用统一数据和金标准比较网络推断方法。*Nature Methods* 9:796–804，DOI [10.1038/nmeth.2016](https://doi.org/10.1038/nmeth.2016)。论文精读见 [Marbach 2012](paper-marbach2012_wisdom.html)。
- **核心发现**：方法可大致分为回归、互信息、相关、贝叶斯网络等类别，各有偏好的网络结构（例如对前馈环、级联的识别能力不同）；没有单一方法全面领先；整合多种方法的社区网络最稳健。
- **阅读提示**：留意不同方法对不同基序的系统性偏差，这把[网络基序](molecular-networks.network-motifs.html)与网络推断联系了起来。
- **思考题**：为什么“整合多种方法”能提高稳健性？在什么情况下整合反而可能放大错误？

### Pratapa 等 2020：Benchmarking algorithms for gene regulatory network inference from single-cell transcriptomic data

- **背景**：单细胞 GRN 推断算法大量涌现，缺乏统一评估。*Nature Methods* 17:147–154，DOI [10.1038/s41592-019-0690-6](https://doi.org/10.1038/s41592-019-0690-6)。
- **核心发现**：BEELINE 框架评估 12 种算法；方法在合成网络上比在布尔模型上表现好，在真实数据上多数方法的早期精度接近随机；不需要拟时序的方法（GENIE3、GRNBoost2、PIDC）总体更准确，且不受拟时序误差影响。
- **阅读提示**：注意作者如何构建模拟数据（用 BoolODE 从已知布尔模型模拟单细胞表达），以及 AUPR 比值、早期精度比等指标的定义。
- **思考题**：如果推断方法在真实数据上接近随机，SCENIC 为什么仍被广泛使用？它的哪一步弥补了纯共表达推断的不足？

## 开放问题 {#questions}

1. 一份表达数据（或其他高维数据，如代谢组、脑区时间序列）在什么条件下适合做共表达网络？预期得到的模块会反映生物学程序、细胞组成，还是技术因素？如何区分？
2. 一篇论文用 WGCNA 在 30 例样本中找到“与预后相关的 hub 基因”，并据此提出治疗靶点。请从样本量、混杂、方向性、外部验证四个角度写出审稿意见。
3. 一个模块在动物模型中定义、在人类组织中 Zsummary 为 6。你会如何表述这个结果？还需要哪些分析才能说“该调控程序在人类中保守”？
4. 设计一个评估方案：你提出了一种整合 ATAC-seq 先验的单细胞 GRN 推断方法。金标准应如何选取才能避免循环论证？应报告哪些指标与基线？
5. 若只有横断面表达数据、没有扰动与时间信息，哪些关于调控方向的结论在原则上无法得出？哪些外部信息（遗传变异、转录因子列表、基序）可以部分弥补？
